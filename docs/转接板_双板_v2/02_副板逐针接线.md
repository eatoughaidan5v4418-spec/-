# 副转接板：侧边PMOD弯针、引脚分配与逐针接线

> **历史外置驱动方案。** 已被[模块插装v3](../转接板_模块插装_v3/00_板卡结构确认.md)取代；副板现在直接插拨叉TMC2209，原5P控制口改为2.0mm的4P电机输出，另需独立电机电源。保留旧表仅供追溯，不作为当前画图输入。

日期：2026-11-07。用于画原理图的v2设计定义；设备原线针序、实物修订版和封装尚须核对，未通过实板验证。

## 1. 结构与连接器数量

本板从星火侧边向外横放，采用两组匹配侧口的2×6弯公排针，J_S001接CN5/PMOD1，J_S002接CN6/PMOD2。两组连接器位置、插入方向和间距必须从实物量取，预留固定支撑，不能由接头承担线束拉力。未确认两组插座能同时刚性插合前，不冻结PCB孔距。

| 类别 | 数量 | 编号/用途 |
| --- | --- | --- |
| 2×6弯公排针 | 2 | J_S001接CN5，J_S002接CN6 |
| 上面2×8备用公排针 | 1 | H_S001，全部未使用PMOD信号 |
| XH5P | 1 | J_S103，拨叉驱动控制 |
| XH4P | 1 | J_S110，串口屏 |
| 2P螺丝电源端子 | 1 | J_S200，外部屏幕电源输入，不计入XH |

**共2个XH、9个XH针位。** 副板所有功能信号都来自PMOD2；PMOD1暂全保留为备用排针。没有板间信号排线，也不把40Pin上的PB15/PE15引过来。

## 2. 副板功能分配

| 功能 | MCU脚 | 星火来源 | 模式 | 方向 |
| --- | --- | --- | --- | --- |
| U_STEP | PD12 | CN6.4 | TIM4_CH1 / AF2 | 输出 |
| U_DIR | PF6 | CN6.8 | GPIO | 输出 |
| U_EN_N | PF7 | CN6.7 | GPIO，低有效 | 输出 |
| HMI_MCU_TX | PB10 | CN6.2 | USART3_TX / AF7 | 输出 |
| HMI_MCU_RX | PB11 | CN6.3 | USART3_RX / AF7 | 输入 |

**相对v1的变化：U_DIR由PB15改为PF6，U_EN_N由PE15改为PF7。** 保持U_STEP=PD12、屏PB10/PB11不变。USART3不启用CTS/RTS，PD12作为TIM4_CH1；PF6/PF7使用普通GPIO。

## 6. 副板电源及外围画法

- PMOD仅提供3.3V，**没有5V**。`V3P3_CORE`来自CN5/CN6的6、12脚；本板经R_S_PWR（0Ω/测流断点）形成`V3_S`，用于拨叉驱动VIO及EN上拉，需核对原板电流余量。不与主板受保护支路V3_M相连。
- J_S200为两位螺丝端子：1=`V5_EXT_S`（外部5V降压输出），2=`GND`。外部5V不得连接到PMOD的3.3V脚，也不通过副板反向给星火供电。
- 屏电源：`V5_EXT_S → JP_HMI5 → VHMI_S`；另留`V3_S → JP_HMI3 → VHMI_S`。两个独立焊桥默认都不装，按屏完整型号和电流预算只选一路；不能同时短接。若实际屏需其他电源则改对应支路，本表不假定仅凭011C就能确定电压。
- 屏信号：`MCU_PB10 → R_S_TX(0Ω，默认不装) → HMI_TO_SCREEN_RX`；`HMI_FROM_SCREEN_TX → R_S_RX(0Ω，默认不装) → MCU_PB11`。两边均留测试焊盘和电平转换接入位置；确认屏TTL电平与3.3V MCU兼容后才装直连0Ω，否则接相应方向的转换器。屏供电5V不代表TX/RX电平必为5V，也不能默认其为3.3V。
- 拨叉控制：`MCU_PD12 → R_U_STEP(33~100Ω候选) → U_STEP_EXT`；`MCU_PF6 → R_U_DIR(33~100Ω候选) → U_DIR_EXT`；`MCU_PF7 → R_U_EN(0Ω) → U_EN_N_EXT`，EN_EXT加10kΩ上拉到V3_S。原始网络与EXT网络命名不同，电阻不能被同名标签旁路。
- 5P端另一端需要对应TMC红排针模块的底座/小转接，将VIO/GND/STEP/DIR/EN按丝印接线；驱动模块本体并非自带这个5P口。VM、动力GND、绕组输出不经副板。模式脚按模块另定，不照搬A4988；本版未增加TMC UART/DIAG。
- V3_S入口留100nF+10µF，屏接口附近预留去耦/储能位置，容量及走线按屏负载核定。PMOD3.3V与外部5V分别标丝印，信号地共参考，电机大电流不经过副板。
- PMOD1上的PA7/PA6/PA5/PE2/PE5/PE3/PE4与星火Spark接口是重复网络，不增加独立GPIO。保留排针可用，但不能同时接冲突的原板扩展模块；PE2~PE5若启用TRACE也需避免占用。

## 7. 现有屏幕和小电机接头的规格补充

实物核对结果：屏幕及大电机线自由端为2.54mm，小电机线端为2.0mm。J_S110按2.54mm配套4P带壳针座图纸画封装，不套JST原厂2.50mm XH封装。42电机本体插座的PH2.0-6P属于电机端另一处接口，不能混同。

已确认两档间距：大电机线端/屏幕2.54mm，小电机线端2.0mm。J_S110按2.54mm配套针座选型，针序和卡扣仍与原屏线对应。小电机的2.0mm接头在独立驱动输出侧另配，不套大电机接头封装。

J_S103是5P拨叉驱动控制口，接TMC的VIO/GND/STEP/DIR/EN，不是小电机绕组接口；小电机原小插头保留，在独立驱动输出侧配对应转接线。这里的“小电机”为当前拨叉轴配置。此次连接器补充不改变副板两个XH的数量和GPIO分配。

## 8. 验证范围

已核对：两组PMOD共24针、5个功能GPIO、11个未分配GPIO均到备用排针、无40Pin信号跨板需求、XH针数。未验证：实物板卡修订版、双侧口间距与弯针机械方向、屏完整型号/电平/原线序、供应商封装、供电预算与上电。先核对机械再画定安装孔，先逻辑测试再连接驱动。
