# 主板四路5V输入适配接线

> **已撤回，不再按本表画主板。** 用户要求不额外加芯片，且后续核实PG3/PG6/PD8/PD9均为FT数字输入；采用[05_霍尔资料核对与主板FT直连](05_霍尔资料核对与主板FT直连.md)。本文件保留历史方案，不再安装U_M401及其配套阻容。

日期：2026-11-08。配套[5V检测定义](03_检测器件5V供电与输出定义.md)、[主板绘制表](01_主转接板原理图绘制表.md)。

## 1. 器件选择

主板四路数字检测输入共用一颗 **SN74LVC14ADR**，位号 `U_M401`，SOIC-14（TI D封装，1.27mm脚距）。EDA搜索完整型号“SN74LVC14ADR”，或搜索“SN74LVC14A”后核对SOIC-14。不是74HC14、74HCT14，也不是把芯片供电接5V。

这颗器件是六路施密特输入反相器；SN74LVC14A供电范围1.65～3.6V，输入允许0～5.5V。在本板VCC=V3P3_OUT时，输出为3.3V逻辑。六路用四路，剩余两路输入固定到GND、输出不连接。施密特输入适用于传感器/上拉产生的较慢边沿，但不代替长线抗干扰或浪涌防护。

新增四颗10kΩ上拉电阻（0805，1%，≥1/8W），用于将开漏/NPN输出的空闲状态定义清楚。每颗从传感器RAW5V网接到V5_SYS；不能接在PG3/PG6/PD8/PD9端再拉到5V。即使输出是推挽，5V下拉低时每颗增加约0.5mA负载，仍需在实物验证时确认模块低电平满足要求。

新增一颗100nF陶瓷去耦（0805，X7R，50V），跨芯片14脚与7脚，PCB时靠近芯片。用户先前不加阻容指的是直连方案，本节为5V传感器接3.3V逻辑新增的必要适配器件。

## 2. U_M401逐脚接线

以下采用SOIC-14封装的脚号。不要按画布上符号左右顺序代替引脚编号。

| 脚号 | 名称 | 连接网络/处理 |
| ---: | --- | --- |
| 1 | 1A | HALL_T_RAW5V，来自J_M140.3 |
| 2 | 1Y | PG3，旋转原点输入 |
| 3 | 2A | HALL_PLATTER_RAW5V，来自J_M141.3 |
| 4 | 2Y | PG6，转运台托盘输入 |
| 5 | 3A | IR_CAR_RAW5V，来自J_M142.3 |
| 6 | 3Y | PD8，车辆检测输入 |
| 7 | GND | GND |
| 8 | 4Y | PD9，手进入检测输入 |
| 9 | 4A | IR_HAND_RAW5V，来自J_M143.3 |
| 10 | 5Y | 不连接，放未连接标记 |
| 11 | 5A | GND，未用输入固定低电平 |
| 12 | 6Y | 不连接，放未连接标记 |
| 13 | 6A | GND，未用输入固定低电平 |
| 14 | VCC | V3P3_OUT，3.3V |

若EDA符号拆成六个门和电源单元，应把六个门及电源单元全部放出，编号属于同一U_M401；不要遗漏供电脚或未用门。

## 3. 四颗上拉电阻逐端连接

EDA搜索“贴片电阻 10k 0805 1%”。电阻无极性，端号在本表中只用于统一表达。

| 位号 | 数值 | 1端 | 2端 |
| --- | --- | --- | --- |
| R_M401 | 10kΩ，0805 | V5_SYS | HALL_T_RAW5V |
| R_M402 | 10kΩ，0805 | V5_SYS | HALL_PLATTER_RAW5V |
| R_M403 | 10kΩ，0805 | V5_SYS | IR_CAR_RAW5V |
| R_M404 | 10kΩ，0805 | V5_SYS | IR_HAND_RAW5V |

不因模块可能带上拉就把芯片输入悬空。板载已有上拉时与本表电阻并联，核对总负载和输出低电平；模块若输出不是0～5V数字信号，不适用本表。AO/DO模块只接DO。

## 4. 去耦电容逐端连接

EDA搜索“贴片电容 100nF 0805 X7R 50V”或“104 0805 50V”。位号 `C_M401`，无极性。

| 位号 | 规格 | 1端 | 2端 |
| --- | --- | --- | --- |
| C_M401 | 100nF，0805，X7R，50V | V3P3_OUT / U_M401.14 | GND / U_M401.7 |

## 5. 一路示意及极性

```text
V5_SYS ── R_M403：10kΩ ──┐
                         │
J_M142.3 ─ IR_CAR_RAW5V ──┴── U_M401.5(3A)
                                  施密特反相
                             U_M401.6(3Y) ── PD8

U_M401.14 → V3P3_OUT
U_M401.7  → GND
C_M401跨14、7脚
```

传感器原始输出高时，GPIO读低；原始输出低时，GPIO读高。GPIO配置普通数字输入，不用内部上下拉作为本电路输入侧上拉的替代。最终“检测到/未检测到”的软件极性按每路模块实测设置，不根据商品“NPN常开”文字统一猜测。

RAW5V与对应GPIO是两个网络，不能另用导线或标签旁路芯片。接口侧供电仍是V5_SYS，不把芯片14脚误接V5_SYS。本节只适配主板四路检测；层板八路输入另行编制接线表。

## 6. 元件与验证范围

本节新增：SN74LVC14ADR×1、10kΩ/0805×4、100nF/0805×1。芯片本体不是0805封装，电阻电容使用0805。
