# 主转接板原理图绘制表 v3

日期：2026-11-08。配套：[板卡结构确认](00_板卡结构确认.md)。这是模块插装主板，**不是旧版外置驱动5P控制转接板**。

> **当前检测定义：霍尔、红外5V供电，红外NPN常开、30cm档、2套。** 四路有源输入按已核实的FT数字输入条件直接接主控，不额外加芯片，详见 [03_检测器件5V供电与输出定义](03_检测器件5V供电与输出定义.md)。不要继续使用旧版3.3V传感器直连表。

## 1. 本次画什么

主板画七个分区：星火40Pin、备用2×8、升降驱动、旋转驱动、检测接口、两层I²C接口、驱动电机电源。TMC2209用现成红排针模块+匹配排母，不画裸芯片。

沿用原理图现有 `PA8`、`PB7` 等网络名。驱动控制和无源开关直接连接；主板霍尔/红外按FT数字输入条件直接接PG3/PG6/PD8/PD9，四脚关闭内部上下拉，不再放SN74LVC14A。绕组输出分别用 `Z_`、`T_` 区分两台电机，不能互连。

## 4. 两块TMC2209模块：先确定功能网络

两块模块分别编号 `DRV_Z`（升降）、`DRV_T`（旋转）。以下是**模块引脚功能到网络的连接表，不是芯片脚号或排母物理针号**。

已从本地PDF第2页确认红/黄排针图示的两列顺序，四条1×8排母的详细编号见 [02_红排针TMC2209排母接线](02_红排针TMC2209排母接线.md)。已确定不用UART、PDN不由载板控制，两脚在载板不连接，采用模块默认独立模式；模块默认配置、静止保持电流、物理封装及插入方向仍待实物核对。

| 模块功能引脚 | DRV_Z | DRV_T |
| --- | --- | --- |
| STEP | PA8 | PA0 |
| DIR | PA1 | PB14 |
| EN / ENN | PD10 | PE14 |
| VIO / VCC_IO | V3P3_OUT | V3P3_OUT |
| 所有GND | GND | GND |
| VM / VMOT | VM_Z_SAFE | VM_T_SAFE |
| M1A / 对应第一组绕组端A | Z_M1A | T_M1A |
| M1B / 对应第一组绕组端B | Z_M1B | T_M1B |
| M2A / 对应第二组绕组端A | Z_M2A | T_M2A |
| M2B / 对应第二组绕组端B | Z_M2B | T_M2B |

EN低有效。去掉外部EN上拉时，复位/下载/启动期间是否误使能仍须验证；固件尽早设EN为高，再初始化脉冲输出。不能把EN硬接GND而失去独立使能。

本地PDF混有TMC2208、TMC2209紫板、红排针、ATD5833，不能按相同外形直接互换。红排针细分表给出两配置位均高对应1/16，但配置位与实物MS1/MS2/M0/M1的映射仍按实物确认。PDN/UART、CLK、NC及额外引脚按准确模块电路分别处理，不统一接地、不全部悬空；本轮暂不启用UART/DIAG，不从星火额外分配信号。

**物理封装确认前的画法：** 先用两组带功能名的模块符号表达本表；若直接画两条1×8排母，必须先对照红排针实物填写针号，不套紫板或A4988的排针编号。模块排母的列间距、顶部视图、插入方向以及散热片空间均待核对。

## 5. 两个电机接口：由旧5P改为4P

| 针号 | J_M101：升降4P，2.54mm | J_M102：旋转4P，2.54mm |
| ---: | --- | --- |
| 1 | Z_M1A | T_M1A |
| 2 | Z_M1B | T_M1B |
| 3 | Z_M2A | T_M2A |
| 4 | Z_M2B | T_M2B |

这里先定义两对线圈相邻的逻辑顺序。**现有电机插头针序尚未验证**；若原线序不同，按实测线圈配对调整本表或线束后再定稿，不能因为都是4P就直接插。M1A/M1B是一组线圈，M2A/M2B是一组，不能按颜色猜。接口不能接V3P3_OUT或GND，不能带电插拔电机。

## 6. 两层I²C：两个4P

| 针号 | J_M120：一层 | J_M121：二层 |
| ---: | --- | --- |
| 1 | V3P3_OUT | V3P3_OUT |
| 2 | GND | GND |
| 3 | PB7 | PB7 |
| 4 | PB6 | PB6 |

PB7=SDA，PB6=SCL。两个接口并联。所购模块JP1.3=SCL、.4=SDA，与本板3/4脚对应编号相反，按功能连线，不能四针顺序直通。MCP模块已带上拉和去耦时本板不重复增加，供电总负载仍须核算。

层板霍尔已改5V，另增加J_M122（一层）、J_M123（二层）两个2P口：1=V5_SYS、2=GND。每层用4芯通信/逻辑供电线和2芯传感器5V线；MCP本身仍用3.3V，不改I²C上拉电压。

## 7. 六路无源开关：2P

| 位号 | 用途 | 1脚 | 2脚 |
| --- | --- | --- | --- |
| J_M130 | 升降回零 | GND | PG0 |
| J_M131 | 升降下限监测 | GND | PG1 |
| J_M132 | 升降上限监测 | GND | PG2 |
| J_M133 | 急停辅助触点监测 | GND | PG7 |

## 8. 四路有源检测：3P

| 位号 | 用途 | 1脚 | 2脚 | 3脚 |
| --- | --- | --- | --- | --- |
| J_M140 | 旋转原点霍尔 | V5_SYS | GND | PG3 |
| J_M141 | 转运台托盘霍尔 | V5_SYS | GND | PG6 |
| J_M142 | DOCK车辆红外接收 | V5_SYS | GND | PD8 |
| J_M143 | DOCK手进入红外接收 | V5_SYS | GND | PD9 |

四个接口按上表直接接同名GPIO。ST已确认PG3、PG6、PD8、PD9为5V容忍FT引脚，须数字输入、GPIO_NOPULL、主控正常供电，模块信号保持规定0～5V。模块输出需有外部上拉/确定电平，不将FT能力推广到层板MCP。撤回U_M401及其配套阻容，详见 [05_霍尔资料核对与主板FT直连](05_霍尔资料核对与主板FT直连.md)。

红外选NPN常开、30cm、2套。新增J_M144（车辆发射头）、J_M145（手部发射头）两个2P供电口，均为1=V5_SYS、2=GND。每层车位霍尔接层检测板，统一5V供电，输出在层板适配后进3.3V的MCP，不在主板重复增加15个霍尔口。AO/DO模块只用DO。

## 9. 可选转台组合口：J_M160，6P

| 针号 | 网络 |
| ---: | --- |
| 1 | V5_SYS |
| 2 | GND |
| 3 | PG4 |
| 4 | PG5 |
| 5 | PG6 |
| 6 | 不接，放未连接标记 |

与J_M150/J_M151/J_M141共用网络，只选一种线束，不能接两套不同传感器同时驱动同一输入。第5脚直接接FT输入PG6，按数字输入和关闭内部上下拉的条件使用；PG4/PG5仍是无源开关输入，不接5V。可不装此口。

## 10. 新增电机电源：J_M200，4P螺丝端子

不使用星火40Pin给电机供电；12V从独立配电与停机/硬限位回路引入。用一个四位端子容纳两组电源：

| 针号 | 网络 | 去向 |
| ---: | --- | --- |
| 1 | VM_Z_SAFE | 升降驱动VM，来自对应动力切断支路 |
| 2 | GND | 升降动力回流 |
| 3 | VM_T_SAFE | 旋转驱动VM，来自对应动力切断支路 |
| 4 | GND | 旋转动力回流 |

VM_Z_SAFE与VM_T_SAFE在板上不互连，避免绕过外部各轴停机/限位切断回路。两组GND与逻辑地共参考，但动力回流要回到电源输入，不能把星火排针地触点当成电机电流的唯一回路。

每组VM至GND附近先预留储能电容位 `C_Z_BULK`、`C_T_BULK`，容量/耐压/封装按现成模块已有电容、线长及电源条件核对后定稿；另核对模块VIO和VM本身去耦。电源储能电容不以“必须0805”为由删去；小阻容若新增仍采用0805，大容量器件规格在核对模块后明确。本轮不凭混合商品说明写死最终电源外围。

V5_SYS来自星火40Pin第2/4脚，现用于备用排针、主板5V霍尔/红外和两层传感器5V分配。不接电机VM，不通过额外5V端子并联外部电源；主板不增加降压芯片。

### 10.1 传感器5V直接取自主控板

不另画5V输入器件。把40Pin第2、4脚的 `V5_SYS` 网络直接引到主板霍尔/红外、两路红外发射头、两层5V供电接口；各路负极接 `GND`。两脚属于同一电源网，不是两路独立电源。

MCP23017和TMC VIO仍用 `V3P3_OUT`，副板PMOD逻辑仍用 `V3P3_CORE`。主板四路传感器输出可按FT输入条件直接连接；层板MCP输入电平另行处理，不能凭主板能直连就认为MCP也支持5V。

上电前按传感器模块实际耗流汇总，并核对主控板上游电源及40Pin供电路径余量。不从GPIO引脚给传感器供电，不从此5V网给步进电机VM供电。

## 11. 绘图顺序与检查清单

1. 保留已经画好的40Pin和2×8，按第2/3节核对，尤其14/30/34脚。
2. 放J_M101/J_M102两个4P电机输出口，不再放5P控制口。
3. 放两组TMC模块功能符号，按第4节画控制、逻辑电源及四根绕组输出网络。物理排母针号待实物核对。
4. 放J_M200动力电源端子与两组VM电源网络，预留必要电源电容位置。
5. 放六个2P无源检测口；四个3P有源检测口用V5_SYS/GND/对应FT数字输入，另加两个2P红外发射供电口，不放适配芯片。
6. 放两个4P层板总线口和两个2P层板5V口；传感器5V统一从40Pin的V5_SYS取电，不放J_M210；最后按需要放可选6P组合口。
7. 复查：每个功能网经正确电路回到对应星火针；两台电机的绕组网络互不相连；VM不连3.3V/5V；配置脚不接地；主板FT输入关闭内部上下拉、信号电压符合条件；MCP/I²C保持3.3V，MCP输入另行处理。
8. TMC实物针序、设置脚、电源外围、电机线圈顺序和封装核对完成后，再做ERC及PCB。仅连通网络不等于通过实板验证。

## 12. 主板元件数量汇总

- 2×20底面直插公排针：1组。
- 2×8备用排针：1组。
- 红排针TMC2209模块插座：2组，通常共4条1×8排母。
- XH2P：10个（无源检测6+红外发射供电2+层板5V供电2）；XH3P：4个；XH4P：4个；XH6P：1个可选。共19个/54针，省略组合口则18个/48针。
- 4P动力螺丝端子：1个，按两轴电流及线径选型，不计入XH。
- 不增加传感器5V输入端子；原J_M210取消，5V从星火40Pin的V5_SYS取得。
- 不安装此前主板适配方案的U_M401、R_M401～R_M404、C_M401；模块实物若缺输出上拉，再补所需电阻，主板不增加额外适配芯片。
- VM储能电容位：每轴1组；最终容量、耐压、封装与模块板载外围共同核定。
- 固定孔/支撑：PCB阶段按实物定位，本轮不画板形和安装孔尺寸。
