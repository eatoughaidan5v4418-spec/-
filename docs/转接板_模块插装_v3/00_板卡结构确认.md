# 两层车库板卡结构确认 v3

日期：2026-11-08。

> **检测供电更新：霍尔及红外统一5V。红外选NPN常开、30cm档、2套。** MCP23017/I²C保持3.3V；主板四路输出按已核实FT条件直连，层板输入独立处理，不加额外适配芯片；详见 [03_检测器件5V供电与输出定义](03_检测器件5V供电与输出定义.md)。旧“3P传感器3.3V直连”定义失效。

## 1. 已确认的设计范围

设计 **3种PCB，实际使用4块**。TMC2209、MCP23017继续使用现成模块，通过排母插到自制PCB上，不重新设计芯片本体电路。模块和载板需要固定，不采用悬吊模块的接法。

| PCB类型 | 实际数量 | 核心内容 | 安装位置 |
| --- | ---: | --- | --- |
| 主转接板 | 1 | 星火40Pin、2×8备用口、两组TMC2209模块插座、两台大电机4P口、检测口、两层I²C口 | 星火上方叠装，底面直排针插入40Pin插座，独立支撑 |
| 副转接板 | 1 | 两组PMOD侧插弯针、2×8备用口、一组TMC2209模块插座、小电机4P口、串口屏4P口 | 星火侧面，独立支撑 |
| 层检测板 | 2，使用相同PCB | 一组MCP23017模块插座、8路5V传感器及输入适配、8路指示灯口、4P总线口、2P传感器5V口 | 每层各固定一块 |

一层装8路车位检测/指示（7车位+DOCK），二层装7路，第8路空置。两层模块地址分别为0x20、0x21。

```text
星火一号
├─ 40Pin → 主转接板
│           ├─ 插升降TMC2209 → 升降电机4芯线
│           ├─ 插旋转TMC2209 → 旋转电机4芯线
│           ├─ XH4P通信/3.3V + XH2P传感器5V → 一层检测板
│           └─ XH4P通信/3.3V + XH2P传感器5V → 二层检测板
└─ 两组PMOD → 副转接板
              ├─ 插拨叉TMC2209 → 小电机4芯线
              └─ XH4P → 串口屏

独立配电/急停/硬限位回路 → 各驱动电机电源输入
独立降压电源 → 星火及串口屏对应电源输入
```

“模块插板”不等于完全无线：电机、传感器、屏幕及跨层总线仍需线束；省去的是模块与载板之间的控制转接线。

## 2. 与旧方案的区别

1. 取消三路驱动的XH5P控制口及外置驱动底座；STEP、DIR、EN在载板内连接模块插座。
2. 主板原J_M101/J_M102改为升降、旋转 **XH4P电机输出**；副板J_S103改为小电机 **4P电机输出**。相同位号的旧5P定义失效。
3. 不把电机绕组线接星火GPIO、3.3V或GND。电机4P只接驱动的两组绕组输出。
4. 主/副板加入驱动电机电源接入。驱动动力电流不经过星火40Pin或PMOD供电触点。
5. TMC控制及无源触点按原方案直连；霍尔与红外主板四路按FT条件直连，不放U_M401；MCP层板输入单独设计、不加额外适配芯片。驱动供电储能/去耦仍需保留，当前方案不再是整板零阻容。

## 4. 接口统计

| PCB | XH2P | XH3P | 4P带壳接口 | XH6P | 合计 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 主板 | 10：开关6+红外发射供电2+层板5V供电2 | 4 | 4：电机2+层板2 | 1，可选 | 19；不装组合口则18 |
| 副板 | 0 | 0 | 2：电机1+屏幕1 | 0 | 2 |
| 每块层检测板 | 8个LED口+1个5V输入口 | 8个霍尔口 | 2个总线口，输入/级联 | 0 | 19个预留接口 |

主板共54个XH针位（含可选6P口），传感器5V从星火40Pin第2/4脚的V5_SYS取得，不增加独立5V输入端子；副板8个4P接口针位。层板是相同PCB，两层各一块；二层第8组检测及LED可不装。LED口暂定2P供板外指示灯，GPIO侧需要限流，不把GPIO裸接LED。本版只推进主板，层板逐针定义后续单独整理。

间距依据实物确认：大电机线端及屏幕2.54mm，小电机线端2.0mm。小电机4P选匹配的2.0mm系列，不套2.54mm封装。其余新定义接口按配套线束选型；2.54mm不等于JST原厂XH的2.50mm。

## 5. 信号与电源规则

- 主板逻辑电源用 `V3P3_OUT`，副板逻辑电源用 `V3P3_CORE`；两条支路不通过载板额外短接。逻辑地共参考。
- 主板两层I²C口均为1=V3P3_OUT、2=GND、3=PB7/SDA、4=PB6/SCL，并联使用。
- 霍尔和红外均从星火40Pin第2/4脚的V5_SYS取5V，取消J_M210独立输入端子。每层另加2P的5V供电线，MCP和I²C仍用原4P的3.3V。传感器总电流须在主控板电源及40Pin连接器余量内；这是电源脚取电，不是GPIO供电。
- MCP模块原理图中，JP1.1=VCC、.2=GND、.3=SCL、.4=SDA；载板4P的3/4脚与模块JP1编号顺序不同，按功能接线。
- 按该模块图：SDA/SCL各10k上拉、RESET上拉、A0/A1/A2下拉、电源电容已在模块上。两块各有10k时总线等效每线5k；无需在主板重复增加，但仍须按实际线长和上升时间验证。
- 一层地址脚按模块下拉默认0x20；二层A0接模块3.3V、A1/A2默认下拉，地址0x21。RESET使用板载上拉，不额外控制；INTA/INTB可先不接，程序轮询。
- 为兼容当前MCP23017资料的输入限制，层板输入使用GPA0～GPA6和GPB0；GPA7及GPB1～GPB7用于8路LED。二层GPB0对应第8组可空置。
- TMC模式按STEP/DIR独立控制，目标1/16细分；MS/PDN/CLK的最终接法必须对应红排针实物，不照抄本地混合资料中的紫板或其他驱动图。
- 屏幕保留外部独立电源输入，不能把未知屏供电接到PMOD3.3V。电平兼容后才允许PB10/PB11直连。
- 微动及急停逻辑监测用常闭触点、内部上拉。主板霍尔和红外3P口为5V/GND/对应FT数字输入，四脚关闭内部上下拉、按05文档条件使用；红外选NPN常开，DO高低极性待实测。未做RC不代表已经验证抗干扰。

## 6. 已核对的纠错

星火40Pin物理针号 **14=GND、30=配置脚、34=配置脚**。使用 `P2_30_CFG`、`P2_34_CFG` 保留后两脚，不在载板强制接地。旧文档中的 `P2_14_CFG` 是错误标注，禁止沿用。

本地官方原理图40Pin叫P2，官方交互BOM中的40Pin叫P1，两份资料位号不同。以40Pin物理针号和当前实物核对，不能把两份资料中的P1/P2直接等同。
