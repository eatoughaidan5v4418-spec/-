# 接口规范冻结（2026-11-03）

用户冻结。软件仍暂停。

## 电机 PWM / STEP
| 信号 | 实现 | 备注 |
|------|------|------|
| N20×N PWM | **PCA9685（I2C）** | 2×2 也用，省事；3×3 同一路线 |
| A4988 STEP | **MCU 硬件定时器** | 推荐 **PA0 / TIM5_CH1** |
| A4988 DIR/EN | GPIO 或扩展 | EN 可进急停链 |
| TB6612 DIR/IN、STBY | GPIO 或扩展 | STBY 可共脚 |

## 输入
| 信号 | 实现 |
|------|------|
| 限位 / 霍尔 | **MCP23017（I2C）** 或数量精简后直连 |
| 急停 | MCU EXTI 优先（安全） |

## 总线
- PCA9685 + MCP23017 走同一 I2C（注意地址与上拉）。
- 板载 RW007 WiFi 保留。

## 采购
- **须加：PCA9685 模块**（16 路 PWM）
- 建议：MCP23017 ×1~2（视限位数量）

## 禁止
- N20/STEP 用普通 GPIO 软咬 PWM/脉冲
