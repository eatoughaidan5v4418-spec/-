# CAD 索引

当前选用两台 24 mm 短轴电机的 v6 试配方案。请优先查看 [v6 装配与说明](./三维装配_v6_夹紧止推限位/README.md) 和 [v6 板件及安装详图](./图纸_v6_夹紧止推限位/README.md)。实际零件、皮带夹持、限位停止距离和结构强度仍需确认，不能直接作为最终加工依据。

交互演示中：
- 存车：系统把空托盘调到 DOCK，用户放车并确认后送入空车位。
- 取车：先选中载车托盘。
- 车辆状态是演示记录，不代表真实传感器读数。
- 模拟急停后，“重置”只恢复网页演示；真实设备需按现场应急程序处理，检查前确保设备停稳、载荷有独立支承并隔离电源。

可运行 `node tools/test_cad_simulation.js` 检查模拟状态机。测试不验证实际机构、电气或三维碰撞。

可运行 `node tools/test_deck_geometry.js` 检查两层甲板的销槽布置。
