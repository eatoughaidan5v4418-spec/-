# 自制件尺寸表与草图顺序（A 版）

单位 mm。坐标系与《建模参数》一致：底板左前角原点，X 右、Y 后、Z 上；井轴心 `(150, 40)`。  
厚度未买死料处给建议值，到货只改厚度不改长宽与孔距。外购件见文末包络，不画内部。

---

## P01 底板

| 项 | 值 |
|----|----|
| 外形 | 300 × 180 × **5**（建议 5～8） |
| 井轴心 | (150, 40) |
| 光轴孔心 | (150±55, 40) → **(95, 40)**、**(205, 40)**；跨距 110 |
| 光轴跨距 | 110（相对轴心对称） |
| 电子净空区 | X 50～250，Y 75～175，高 40（底仓避让，非挖穿） |
| 电机座孔 | 31×31 正方形，中心 (150, 40) |
| 后缘预留 | USB 窗、12V Φ8（具体开在后挡板 P32，底板上可不开） |

**草图顺序**

1. 草图：矩形 300×180，原点左前角。  
2. 点：轴心 (150,40)；两光轴心，跨距 110。  
3. 孔：电机 31×31 四孔（按 NEMA17 标准孔距，中心同轴心）。  
4. 可选：铜柱孔（星火四角，板未到先按 120×84 包络四角 M3 预留）。  
5. 拉伸厚度 5；倒角外缘 1×45°（可选）。

## P02 / P03 外框 2020 下料

| 件 | 数量 | 长度 | 备注 |
|----|------|------|------|
| 立柱 | 4 | **260** | 截面 20×20 |
| 底长梁（X） | 2 | **300** 外廓用，净长按角件扣减 | 与立柱角件连接 |
| 底短梁（Y） | 2 | **180** 外廓用，净长按角件扣减 | |
| 顶梁 | 同底 | 同底 | 对称 |

外包络目标约 **300 × 180 × 260**。角件、T 母外购。

**草图/装配顺序**

1. 按表下料 2020。  
2. 底板铺平 → 四立柱角件「可调」预拧。  
3. 底/顶横梁合框 → 校对角后再拧紧。

## P04 / P05 一层、二层梁（轨撑）

| 项 | 值 |
|----|----|
| 层距（轨面） | 100 ± 1 |
| 单格净空 | 140 × 80 |
| 中列井口 | 140 × 80（对接口） |
| 格心距 | 长向 140、宽向 80 |

**草图顺序**

1. 在外框高度上定一层、二层轨面基准（层距 100）。  
2. 两侧布置 2×2 格线，中列留井。  
3. 梁上预留滑轨安装孔（按所选 MGN7 孔距，到货按实物改）。  
4. 齿条安装面朝层内，长度覆盖行程 120～150。

## P20 托盘板（×6）

| 项 | 值 |
|----|----|
| 外形 | **140 × 80 × 7** |
| 材料 | 亚克力/铝板（采购亚克力可裁） |
| N20 座 | 板底或侧边，按电机安装孔（到货描孔） |
| 滑块连接 | 与 MGN7C 滑块孔对齐（到货描孔） |
| 车模区 | 中央约 105×43 无螺钉头凸起 |

**草图顺序**

1. 矩形 140×80。  
2. 拉伸 7。  
3. 族表/派生 ×6。  
4. 滑块孔、N20 孔：实物到位后打孔或二次加工。  
5. 四周倒角 1～2，防刮车模。

## P14 升降台

| 项 | 值 |
|----|----|
| 外形 | **140 × 80 × 7**（厚可与托盘同） |
| 丝母孔 | 台中心附近，配 T8 丝母外径（到货） |
| 直线轴承孔 | 两孔，跨距 **110**，与光轴同心 |
| 口部 | 对接边倒角 ≥2 |
| 磁铁位 | 台侧，对应霍尔 Z=55/155 |

**草图顺序**

1. 矩形 140×80 → 拉伸。  
2. 中心丝母沉孔/通孔。  
3. 两轴承孔，间距 110，对称于丝杆轴。  
4. 对接边倒角。  
5. 侧壁磁铁沉孔（Φ 按磁铁）。

## P10 电机座 / 丝杆下座

| 项 | 值 |
|----|----|
| 位置 | 井底，轴心 (150, 40) |
| 孔距 | **31 × 31**（NEMA17） |
| 中心孔 | 过轴/联轴器让位 |

**草图顺序**

1. 座板草图，中心 (150,40)。  
2. 31×31 四孔 + 中心让位孔。  
3. 固定到底板或井底横梁。

## P13 光轴支座安装

| 项 | 值 |
|----|----|
| 光轴 | Φ8 ×2，长约 300 |
| 跨距 | **110** |
| 下支座 Z | ≈ **15** |
| 上支座 Z | ≈ **245** |

**草图顺序**

1. 支座孔 Φ8（或按外购支座底孔）。  
2. 安装板孔位保证与丝杆平行。  
3. 先点固，手转丝杆无卡再终拧。

## P31 DOCK 下层导板

| 项 | 值 |
|----|----|
| 位置 | 下层前侧入口 |
| 对齐 | 下层对接格 140×80 |
| 倒角 | 入口导边 ≥ **2** |
| 净空 | 车模 105×43×30 进出留余量 |

**草图顺序**

1. 前开口与对接格共线。  
2. 导板厚度自定（3～5）。  
3. 内外倒角，去锐边。

## P30 正面 TJC 面板开孔

| 项 | 值 |
|----|----|
| 可视孔 | 约 **95 × 54**（TJC4827T143） |
| 固定 | 四角螺钉孔（按模组安装孔，到货描孔） |
| 线 | 弱电槽走向底仓；不挡 DOCK |

**草图顺序**

1. 面板外形贴外框正面。  
2. 开 95×54 矩形（可加 R2 圆角）。  
3. 四角孔。  
4. 屏后装，先开孔后装玻璃/屏。

## P16 / P24 限位与霍尔支架（简易）

| 触发 | Z 或位置 |
|------|----------|
| 下硬限位 | Z ≈ 28 |
| 一层霍尔 | Z ≈ 55 |
| 二层霍尔 | Z ≈ 155 |
| 上硬限位 | Z ≈ 175 |
| 层内微动 | 每盘行程两端 |

**草图顺序**

1. L 形或打印支架，槽孔可调 ±3。  
2. 磁铁在升降台侧；霍尔在立柱/井壁。  
3. 微动撞块在托盘行程端。

## 推荐建模顺序（对照本表）

1. P01 → P02/P03 → P04/P05  
2. P20 ×6 → P21 轨（外购）  
3. P10 → P13 → P14 → P16  
4. P31 → P30 → P32/P33  
5. 总装检查：Z=55/155 共面；DOCK 过车模  

卡顿先查平行与倒角；勿改已冻结长宽、格距与 Z 对接点。
