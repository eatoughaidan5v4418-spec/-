# 2×2 样机自制件尺寸与草图顺序

冻结依据：结构 v1.2；升降孔距表 v1；底仓示意 v2；装配顺序 v1。  
单位：mm。未注公差：线性 ±0.5；安装孔 ±0.2。

## 总坐标约定

- 整机原点：底板**左前角上表面**，X→右（长向 300），Y→后（宽向 180），Z→上。
- 升降井俯视中心参考：约 (150, 40)（电机轴心，略偏后 −8 已并入 Y=40 标定，与孔距表「轴心 (0,−8) 相对井心」一致时，井心取 (150, 48) 亦可；**自制件以下表绝对坐标为准**）。
- 层高模数：100；一层对接 Z=55；二层 Z=155；下硬限位 Z=28；上硬限位 Z=175。
- 光轴跨距：110（轴心 X=95 与 X=205，即 150±55）。

---

## 1. 底板

**外形：** 300 × 180 × 5（亚克力/木板/铝板，厚可 3–5，表内按 5）

**关键孔位（孔心，相对左前原点）：**

| 用途 | X | Y | 规格 |
|------|---|---|------|
| NEMA17 安装（相对轴心 150,40） | 150±15.5 | 40±15.5 | M3×4，方距 31 |
| 光轴下支座左 | 95 | 40 | 按支座孔拷贝，常用 M4 |
| 光轴下支座右 | 205 | 40 | 同上 |
| 共地铜柱 | 150 | 80 | M3 或 M4 |
| 星火铜柱区（包络内四角，孔距待实物） | 中心约 115,120 | — | M3，暂按包络 120×84 四角各缩进 5 |
| 驱动托板铜柱区 | 中心约 210,130 | — | M3×4，托板约 100×70 |
| 扩展板 PCA/MCP 预留 | 180–240 区四角 | 75–115 | M2.5/M3 |
| 后框 USB 窗中心（边侧立板另开，底板上仅让线） | 110 | 175 | 腰圆 16×10 可选 |
| 12V 线过孔 | 200 | 175 | Φ8 |
| 外框立柱投影（角件孔） | 10,10 / 290,10 / 10,170 / 290,170 | — | M4，随角件 |

电子净空区（不挖空，仅禁干涉）：X50–250，Y75–175，上方净高 40。

**草图/特征顺序：**
1. 矩形 300×180 基体。
2. 标记前边 Y=0、后边 Y=180。
3. 点出电机轴心 (150,40)，阵列 NEMA17 四孔。
4. 点出光轴 (95,40)(205,40) 支座孔。
5. 电子区铜柱孔与共地孔。
6. 后缘过线孔。
7. 四角立柱/角件孔。
8. （可选）底面倒角去毛刺。

## 2. 托盘（×6，相同件）

**外形：** 140 × 80 × 7（若用 3 mm 亚克力作面板，可加 4 mm 加强框，总高约 7）

**关键孔/槽（原点：托盘左前角上表面；前进方向 +Y 朝井）：**

| 用途 | 位置 | 规格 |
|------|------|------|
| 滑块安装 | 底面，沿长向两侧各一排 | 按所买滑轨孔距拷贝 |
| N20 电机座 | 建议右侧边中部，X≈125–135，Y≈30–50 | 按 N20 法兰/抱箍 |
| 齿轮中心 | 与齿条啮合高对齐层梁齿条 | 轴 Φ3 |
| 齿条相对 | 齿条在**固定层梁**上；托盘只装齿轮 | 模数 0.5 |
| 限位撞块接触边 | 前后端面中点 | 与微动滚轮对正 |
| 车位防滑 | 上表面中心区 105×43 内 | 贴胶或浅槽 |

**草图/特征顺序：**
1. 矩形 140×80×7。
2. 上表面倒角 1×45°（四边，防刮车）。
3. 底面滑块安装孔（按实物滑轨）。
4. 侧边 N20 座孔/抱箍位。
5. 端面限位撞块平面修平。
6. （可选）上表面车位轮廓浅刻。

---

## 3. 升降台

**外形：** 140 × 80 × 7（与托盘同规格，口部加倒角）

**关键孔位（原点：台面左前角；台中心对齐井轴心时，整机下台面中心 ≈(150,40)）：**

| 用途 | 相对台中心 | 规格 |
|------|------------|------|
| 丝母孔 | (0, −8) 偏后，即近 Y 小侧 | 按 T8 丝母法兰 |
| 左直线轴承 | (−55, −8) | Φ8 轴承座 |
| 右直线轴承 | (+55, −8) | Φ8 轴承座 |
| 霍尔磁铁 | 台侧立面，高度对齐传感器 | Φ5–6 沉孔或胶粘位 |
| 导轨口倒角 | 与层轨对接的两边 | ≥2×45° 或喇叭口 |

**草图/特征顺序：**
1. 矩形 140×80×7。
2. 台心定位，打丝母孔与左右轴承孔（跨距 110）。
3. 对接边倒角/喇叭口。
4. 磁铁位。
5. 底面加强筋或金属角码安装面（连接丝母座与轴承座成刚性架）。

## 4. 2020 外框下料

**外廓目标：** 约 300 × 180 × 260

| 名称 | 截面 | 长度 | 数量 | 备注 |
|------|------|------|------|------|
| 立柱 | 2020 | 260 | 4 | 可按型材端到端净高微调 |
| 底长梁 | 2020 | 260–280 | 2 | X 向，内侧净距配合底板 300 |
| 底宽梁 | 2020 | 140–160 | 2 | Y 向 |
| 顶长梁 | 2020 | 同底长 | 2 | |
| 顶宽梁 | 2020 | 同底宽 | 2 | |
| 一层横梁 | 2020 | 按跨距 | 4–6 | 轨面高对应 Z≈55 层结构 |
| 二层横梁 | 2020 | 同 | 4–6 | 轨面高对应 Z≈155 |
| 角件 | 2020 | — | ≥30 | M4+T 型螺母 |

下料余量：型材总长建议采购 **1.5–2 m 一根起**，按实量截。

**草图/特征顺序：**
1. 定外廓 300×180 底框矩形。
2. 立柱四角，高 260。
3. 顶框闭合。
4. 按 Z=55/155 加层横梁（先点焊/轻拧，校水平后再紧）。
5. 中列让出升降通道 140×80 投影。

## 5. 层梁 / 导轨固定条

**功能：** 固定微型滑轨与齿条；保证格心距长向 140、宽向 80。

**单层网格（俯视，示意格心）：**

| 格 | 格心约 (X,Y) | 备注 |
|----|--------------|------|
| 左前 | 80, 70 | 近 DOCK/井一侧按实布 |
| 右前 | 220, 70 | |
| 左后 | 80, 140 | |
| 右后 | 220, 140 | |
| 升降对接格 | 150, 40 区 | 中前井口，非停放格 |

（格心可按外框内侧净空整体平移，**保持相对间距 140/80**。）

**单根导轨固定条（示例）：**
- 条宽 15–20，厚 3–5，长 120–150（随滑轨）。
- 安装孔：按滑轨本体拷贝。
- 齿条座：模数 0.5，有效齿长 ≥ 步距+10（长向步距 140，宽向 80）。

**草图/特征顺序：**
1. 在层平面画 2×2 格心。
2. 每格两侧画导轨中心线。
3. 固定条轮廓与孔。
4. 齿条安装基准面（与 N20 齿轮中心高一致）。
5. 交叉口倒角/让位，防托盘换向剐蹭。

## 6. DOCK 下层入口导板

**约束：** 人只在下层 DOCK 放/取；对齐一层对接。

**外形建议：**
- 入口净宽 ≥ 80+裕量（与格宽一致方向），净高 ≥ 车高 30+托盘+2 净空。
- 导板厚 2–3；内口倒角 ≥2×45°；两侧挡边高 5–8。
- 安装于外框前立面一层高度，中心约 X=150，导引至井口/一层轨。

**草图/特征顺序：**
1. 正面开口矩形（按托盘 140×80 投影放宽 2–4）。
2. 左右导板对称。
3. 倒角与挡边。
4. 与一层轨共面校准面。
5. M4 固定孔接前横梁。

---

## 7. TJC 面板开孔（正面）

**屏：** TJC4827T143，4.3 寸电阻屏；可视约 95×54；串口 USART2；机内 5V。

**开孔（面板坐标系：孔中心为屏视窗外接中心）：**

| 项目 | 尺寸 |
|------|------|
| 可视开孔 | 95 × 54（可各边 +0.5 间隙） |
| 模组沉台/外壁让位 | 按商家整模外形，常见约 105×65 级，**以实物为准** |
| 四角固定孔 | 在模组安装耳，孔距待实物；暂预留 M3 四孔对称 |

**安装高度建议：** 正面中上部，不挡 DOCK 口；线从弱电槽入底仓。

**草图/特征顺序：**
1. 面板外形（可与前罩一体或独立亚克力板）。
2. 中心定位，开 95×54 窗。
3. 沉台或后托架。
4. 四角孔。
5. 走线缺口。

## 8. 限位 / 霍尔支架

**层内微动支架（每方向两端，随托盘数配置）：**
- 小板 20×12×2；微动螺钉孔按 SS-5 或所买滚轮微动。
- 撞块高度与托盘端面中线齐。

**升降硬限位：**
- 下：触点高 Z=28；上：Z=175；（可选贴顶 Z=250）
- 支架固定于立柱/光轴支座旁。

**霍尔支架：**
- 一层感应中心 Z=55；二层 Z=155。
- 霍尔对台侧磁铁，间隙 2–5。

**草图/特征顺序：**
1. 选微动/霍尔实物，描安装孔。
2. L 型支架臂长保证触点到 Z 目标。
3. 立柱侧 M4 长孔（可调 ±3）。
4. 3D 打印或铝板折弯。

## 9. 光轴支座安装板

**光轴：** Φ8 × L=300（采购按 300 记账）×2；跨距 110。

| 支座 | Z | 轴心 X | Y |
|------|---|--------|---|
| 下左 | 15 | 95 | 40 |
| 下右 | 15 | 205 | 40 |
| 上左 | 245 | 95 | 40 |
| 上右 | 245 | 205 | 40 |

若支座为外购成品，本「板」可为 2020 横梁上的垫板：厚 3，长 40，宽 20，中心 Φ8 或按支座底孔。

**草图/特征顺序：**
1. 定跨距 110、Y=40。
2. 下/上横梁高度 Z=15/245。
3. 支座底孔拷贝。
4. 装配时先锁光轴、再锁丝杆座，校平行。

## 10. 电机座孔（NEMA17）

**轴心：** (150, 40)（底板坐标）  
**孔：** 相对轴心 31×31 方距，M3×4：

- (150+15.5, 40+15.5)
- (150+15.5, 40−15.5)
- (150−15.5, 40+15.5)
- (150−15.5, 40−15.5)

**丝杆相关（同轴）：**
- 下法兰座安装面 Z=40
- 上导向座 Z=240
- 丝杆 L=300（采购），有效行程覆盖 28→175

**草图/特征顺序：**
1. 底板点轴心。
2. 阵列四孔。
3. 法兰座外形让位（防干涉联轴器）。
4. 电机下方散热/接线空间 ≥10。
