# v3 板件三视图完善版

按项目文档和用户提供的硬件资料绘制。每张图均有 AutoCAD DWG 和 DXF；尺寸单位 mm，采用第一角投影。旧草案保留在相邻目录。

| 图纸 | 内容与状态 |
|---|---|

| [P02 底板 DWG](./P02_底板.dwg) / [DXF](./P02_底板.dxf) | 520×520×6；SHF8 红色候选孔及坐标待实物复核。 |
| [P03 原转运台底板 DWG](./P03_转运台底板.dwg) / [DXF](./P03_转运台底板.dxf) | 170×66×3；已购 3 寸转盘与原板边距存在冲突。 |
| [P03B 局部加宽备选 DWG](./P03B_转运台底板_局部加宽备选.dwg) / [DXF](./P03B_转运台底板_局部加宽备选.dxf) | 中部 96×96、端部宽 66；孔组旋转 20°的备选方案，须验证装配。 |

| [P06 二层甲板 DWG](./P06_二层甲板.dwg) / [DXF](./P06_二层甲板.dxf) | 补充隐藏线、可见投影、缺口宽度及槽口放大图。 |

[P01 无孔空白板闭合轮廓 DXF](./托盘空白板轮廓/P01_托盘空白板_无孔轮廓.dxf) 是独立的 1:1 单条闭合轮廓，只表达托盘外形，不含销孔、磁铁孔或挡车件孔。可用于纸样和与加工方核对，切割前仍需确认材料、板厚及加工公差。

图中红色的 PROPOSED_HOLES 和 PROPOSED_HIDDEN 是候选孔及对应隐藏线；青色十字是轴线参考。红色孔径与孔位**没有冻结**，不能当作实际切孔路径。甲板的 HIDDEN 为根据当前井槽轮廓推导的投影；局部详图为 3:1，尺寸实体显示的是实际数值。

**整套图纸尚不能作为完整加工图。**采购件公差、装配高度、轴端、支架、紧固与三维干涉仍需处理，具体差异、计算和候选孔坐标见 [安装核对](./安装核对.md)。

## 本地复核

```powershell
py tools\check_cad_detailed_v3.py
node tools\test_deck_geometry.js
```

重新生成时为避免覆盖，指定一个不存在的目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\create_cad_v3_detail.ps1 -OutputDir E:\新的图纸目录
```

生成器针对本机 AutoCAD 2025 简体中文版；甲板隐藏线从保留的旧草案俯视轮廓推导。如果以后更改甲板形状，应同步更新来源、重新生成并复核。
