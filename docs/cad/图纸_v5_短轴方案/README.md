# v5 短轴方案板件图纸

**版本提示：**当前请优先查看 [v6 图纸](../图纸_v6_夹紧止推限位/README.md)；v6 转运板和顶部支承已修改，不能与本版混用。

本目录与 [v5 短轴三维装配](../三维装配_v5_短轴方案/README.md) 对应，单位 mm。红色安装孔、沉孔及相关尺寸为候选位置，必须核实已购零件、打印精度、紧固件和安装空间后再加工；底座强度、导轨安装孔、甲板固定和限位等尚未设计完成。
