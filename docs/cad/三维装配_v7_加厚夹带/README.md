## 夹带与间隙

| 项目 | v6 | v7 名义值 |
|---|---:|---:|
| 夹带背壁 | 避轮切削后最薄约 0.55 | 保留完整 2 |
| 夹带底挡边 | 厚 0.5 | 厚 1，距转运板 0.5 |
| 两端带轮至背壁 | 避轮半径额外留 0.4 | 两端极限越程处约 1.41 / 1.82 |
| 皮带外包络至圆形井口 | 约 1.36 | 约 3.50 |
| 停放托盘内端 / 定位销 | r97 / r107 | r100 / r107 |
| 正常推拉 / 机械止挡 | 0～138 / −2、140 | 不变 |

以转运台旋转中心为原点、推拉方向为 `u`：电机轮心由 `u=−72` 移至 `−74`，惰轮由 `u=83.5` 移至 `87.5`，皮带中心线为 `w=−23.5`；夹座相对拨叉向惰轮方向移 0.5。皮带和带轮上移 0.5，配合更厚的底挡边。背壁不再用带轮形状削薄。以上按带轮外径 **13**、轮宽 **6**、皮带宽 **6**、单层厚 **1.4** 建模，均须按实物复尺，包括轮缘、轮毂及安装高度。

连续包络检查将简化的两个带轮分别沿拨叉相对行程 **−2～140** 扫掠，并在径向和轴向各扩大 **0.99 mm**：该包络与整个拨叉实体不相交；同时用实体体积探针检查 2 mm 背壁和 1 mm 挡边内部。两端 1.41 / 1.82 是背壁角点至假设轮体的平面名义距离；**0.99 mm 才是本次对整件拨叉与假设轮体证明的连续间隙下界**。该检查不含实际带轮挡边、偏心、张紧、变形或安装误差。

压片仍按金属 **14×5.6×1.6**、两颗 M2×3 平端紧定螺钉及两只 M2 螺母近似；皮带端部名义搭接仅 6。长皮带在模型中是闭环包络，实际两端的弯曲、齿形、压片接触、张紧与受力未建模。必须先做实物装配和拉脱、防滑、往复循环试验，必要时更换或重设计端部锚固。

## 配套板件与影响

P03E 为 **183×96×3** 轮廓范围，左侧安装耳至 `u=−90`，右侧惰轮耳至 `u=93`；电机三孔和惰轮孔随新位置调整。需至少 183×96×3 的毛坯；旧 P03D 孔位和毛坯不能直接套用。孔边距、螺纹与安装方式仍需实配。

P05R、P06R 的圆形井口从 **R96 扩至 R102**，销槽、支撑臂槽与二层 DOCK 缺口同步接入新圆弧。P01N 托盘仍为 **125×60×3**，但定位销中心改为距内端 **7**；销的位置保持 `r=107`，使停放托盘整体外移 3，内端从 `r=97` 移至 `r=100`，外端至 `r=225`。中央托盘及停放托盘同步移动，拨叉行程和销轨迹不变；旧托盘销位不能直接混用。

假设皮带外包络最大径向为 R98.50，距停放托盘内端名义至少约 **1.50**，覆盖任意相对转角；假设电机方形包络最大径向约 R95.79，距托盘内端至少约 **4.21**。托盘内端中心处有约 **2 mm** 伸入 R102 井口，外端靠近塔架。中央托盘外端为 `u=87`，两条支撑条外端为 `u=78.5/85`，名义悬出分别为 8.5 / 2 mm；负侧支撑条改为长 138.5 mm，距绕轮皮带和直线皮带的名义间隙约 1.11 / 1.00 mm；需实测载盘刚度、支承范围、定位销连接及交接时的变形。轮缘、线束、偏心和安装误差均未计入。井口及销位改变后，旧版甲板图、托盘图和网页演示不再对应。

## 检查及下一步

随模型提供基准姿态、升降旋转离散采样、一层载盘和空叉推拉，以及两端越程记录。常规全装配检查是离散采样；只有上面描述的拨叉与简化轮体做了连续包络检查。未检查其他车位的连续推拉、真实带齿及带端、皮带张力、线束、夹持力、载荷、振动或防坠。止挡和微动开关的动作距离、强度及安全回路也未验证，不能依赖打印止挡防坠。

复尺实际带轮、带厚、开关和电机；先打印夹座小样并做拉脱、往复试验，再复核新托盘销位、加大井口后的托盘支承及低速空载全行程。其他止推、开关和电机轴等待核事项沿用 [v6 说明](../三维装配_v6_夹紧止推限位/README.md)。

在仓库根目录运行：`py tools/check_garage_assembly_v7.py`、`py tools/check_garage_stl_v7.py`、`py tools/check_cad_v7.py`、`py tools/check_cad_v7_details.py`；可用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/verify_3d_assembly_v7.ps1` 和 `tools/verify_cad_v7_drawings.ps1` 在 AutoCAD 中重开检查。

如需在 AutoCAD 2025 中重新生成，请为两个生成器分别指定不存在的新 `-OutputDir`。`tools/create_cad_v7.ps1` 可用 `-ProjectionDir docs/cad/图纸_v7_加厚夹带` 读取当前甲板投影，然后用 `tools/create_cad_v7_details.ps1 -OutputDir <新图纸目录>` 补充安装详图；`tools/create_garage_assembly_v7.ps1` 生成三维实体、STL 与检查记录。
