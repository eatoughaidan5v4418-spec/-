# 2×2 样机建模参数

单位：mm。先零件、再子装配、再总装；不要在总装里直接拉伸整机。

## 坐标系

- 原点：底板左前角
- X 向右（长 300）、Y 向后（宽 180）、Z 向上
- 升降井轴心（底板）：`(150, 40)`

## 建模步骤

1. P01 底板画线  
2. P02/P03 外框  
3. P04/P05 两层 + 中井  
4. P31/P30 DOCK 与屏孔  
5. P20 托盘族表 ×6  
6. P21 滑轨  
7. 升降子装配 P10–P16  
8. P34 底仓净空  
9. 总装：Z=55/155 共面检查后导出  

厚度未买死料前用建议值；长宽、格距、Z 对接点已冻结勿改。
