这些图是**设计草案，不能直接下料或加工**。甲板的主视图和左视图只示外轮廓，未完整表达内部隐藏线；孔位、公差、材料、紧固方式和与实物配合等均需补充。拨叉、升降平台、导条、挡车件等缺少足够细节，本批没有将其假定成可加工零件。

图纸按 AutoCAD 原生线、圆弧、文字和尺寸实体绘制；甲板圆弧为 R96 真圆弧。轮廓由独立实体组成，未整理为激光切割闭合多段线。尚未设置正式图框、打印布局或比例。

## 复核与重新生成

在项目根目录执行：

```powershell
py tools\check_cad_drawings_v3.py
node tools\test_deck_geometry.js
```

若需要重新生成，先启动 AutoCAD，指定**不存在的**新目录以避免覆盖现有文件：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\archive\cad\create_cad_v3.ps1 -OutputDir E:\新的图纸目录
```

当前生成脚本针对已安装的 AutoCAD 2025 简体中文版及其公制模板。生成后仍需重新核对图纸与源方案。
