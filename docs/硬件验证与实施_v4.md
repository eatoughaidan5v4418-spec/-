## 2. 下单与画板前要确认的事项

1. 向卖家或按实物确认：T8 丝杆确为单头、导程 2；NEMA11 的扭矩和额定电流；转盘轴承的厚度和孔位。
2. 实物复尺：GT2 带轮外径、轮宽、轮缘，皮带厚度，微动开关动作距离，电机轴长。
3. 打印 1:1 甲板纸样，与实物导杆、轴承、支座比对后再切亚克力。
4. TMC2209 红排针模块：正反面丝印、16 针物理顺序、细分配置脚、板载电容。
5. 霍尔模块：有磁 / 无磁时 DO 的实际电压，是否自带上拉，上拉接到哪里。
6. 红外对射：遮挡 / 无遮挡时输出电压。
7. 串口屏：标签上的完整型号后缀，对应的供电电压和串口电平。
8. 电机线束：用万用表找出两组线圈，确定 4P 针序。

## 3. 实施顺序（先一层）

每一步都有明确的通过条件。前一步没过，不要往下做。

| 步骤 | 做什么 | 通过条件 | 记录 |
|---|---|---|---|
| 1. 托盘与甲板手推 | 切一块甲板局部和 2 块托盘，人工推拉托盘跨过交接缝，加最大预期载荷 | 不卡边、不翻转 | 推力、卡滞位置 |
| 2. 夹带座小样 | 打印夹座，装皮带做拉脱和往复 | 不滑脱 | 拉脱力、循环次数 |
| 3. 转运台单独验证 | 转运台固定在甲板高度，用 ±8 mm 垫块模拟升降，做入销、拉回、推出、脱开 | 连续 100 次 | 失败次数和原因 |
| 4. 升降塔 | 装立柱、导杆、丝杆和平台，低速回零，在 Z=92/100 往返；逐步提速 | 不丢步、不卡滞；**满载断电不下滑** | 最高可靠速度、重复定位、倾斜、温升、下滑量 |
| 5. 旋转标定 | θ 回零，8 个方位逐一标定 | r=107 处重复误差 ≤0.5 mm | 各方位误差 |
| 6. 一层完整演示 | 7 车位 + DOCK：存满、逐车取出、空闲预置、取消存车、急停恢复、DOCK 防手入 | 连续循环无故障 | 循环次数、故障记录 |
| 7. 加装第二层 | 装二层结构和层检测板（0x21），补录标定 | 自动识别层数；Z=182/190 啮合正常 | 前角挠度 |

## 4. 固件联调顺序

1. 单轴：一台 TMC2209 + 一台电机，定时器输出脉冲，先匀速再加梯形加减速。
2. 回零：微动开关和霍尔原点。
3. I²C：扫描并读写 MCP23017。
4. 界面：先用板载屏 + LVGL 调试界面联调（`garage_ui.c`），副转接板和串口屏工程就绪后切到 TJC 串口屏。
5. 线程：安全监测、运动、调度、人机四个线程，按仿真测试用例回归。
