# 电气接线与走线初审 v1

日期：2026-11-06。对象：星火一号主控、三轴塔式车库，一层样机优先，机械以 v7 试配为准。

**状态：接线架构与走线路径建议，尚不是可直接照接上电的最终电路图。** 本次核对了仓库文档、开发板原理图、驱动与电机资料及芯片厂商资料；没有实物测量、通电、示波器测试或包含线束的运动干涉验证。原有方案与 CAD 未修改。

## 1. 当前项目具备什么，还缺什么

当前确定的架构是：升降 Z、旋转 θ、拨叉 U 三轴；车位层没有电机，每层用 MCP23017 汇集霍尔及 LED。已提供 TMC2209 红色排针模块资料，因此本建议以它为驱动对象，不沿用采购表的 A4988 接法和调流方法。

仓库有开发板原理图，但尚未找到整机电气原理图、最终引脚表、线束表或固件工程。机械 v7 已把井口改为 R102、转运板改为 P03E，**线束仍未纳入其碰撞检查**。不能因为机械零件检查通过，就认为电缆已有空间。

优先解决的缺口：

| 问题 | 本次建议 |
|---|---|
| 旧方案用 MCP23017 GPA0～7 接 8 个霍尔 | 改分配；厂商 DS20001952D 明确 GPA7、GPB7 仅作输出，见第 5 节 |
| 一层 GPB 同时接 2 路 DOCK 光电和 LED，只剩 6 个 LED 输出，与 8 个 LED 清单不一致 | 两路 DOCK 光电独立接主控，层板用于 8 个托盘检测和 8 个 LED |
| 旋转电缆只写“留线环”，没有结构 | 单独设计升降平台到旋转台之间的柔性连接，并补做全行程检查 |
| 采购写 7 个微动，CAD 只建了上下 Z 限位和拨叉两端共 4 个开关座 | 补 Z 回零、独立限位监测的安装位置与接线端点 |
| 屏幕仅确认到 011C，完整后缀未确定 | 暂不冻结屏电源电压、接插件针序和电平适配 |
| 已购 42 电机是长轴版本，但对应铭牌未核实 | PDF 电流与插座定义只能作候选，实物核对后再定限流和相线 |

## 2. 推荐的物理布置与线束树

主控、三块驱动、降压模块、继电器和接线端子，先集中安装在底座外缘可检修区域；具体左右位置需结合实物空间决定。电源/电机端子与传感器/通信端子分区，驱动留散热空间。升降中心下方要给运动件留空，不能随意铺满电路板。

```text
底座固定电控区
├─ 固定短线 → 升降电机
├─ 固定线束 → 屏幕、急停、复位、Z 回零及上下限位
├─ 沿外框固定立柱 → 一层 MCP23017 → 二层 MCP23017
│                       └─ 各自甲板下的车位霍尔、LED
├─ 沿前侧固定框架 → DOCK 光电
└─ 67.5° 方位的竖向拖链 → 升降平台分线点（只升降）
                             ├─ 旋转电机本体
                             ├─ θ 原点霍尔（建议安装于不旋转侧）
                             └─ 旋转柔性连接 → 转运台分线点
                                                 ├─ 拨叉电机
                                                 ├─ 拨叉收回/伸出开关
                                                 └─ 转运台托盘霍尔
```

三条走线规则：

1. **车位层的线固定走，不进拖链。** 每个霍尔就近接本层板，线固定在甲板下及外框上，避开托盘定位销、井口、支撑臂槽与斜撑接触位置。层间总线沿固定立柱走。
2. **旋转电机的四根相线只经过升降拖链，不经过旋转线环。** 电机本体装在升降平台上，其轴转、本体不转。
3. **只有拨叉电机和旋转台上的检测件跨越旋转连接。** 两端微动装在转运板上，并不跟着拨叉滑块移动；按当前机械方案，拨叉的 138 mm 平移行程不需要再加一条活动线。θ 原点霍尔固定在随升降但不旋转的平台，触发磁铁固定在旋转侧。

### 旋转处是最先试配的部位

v7 中心有旋转轴、法兰和隔套，不能把中心孔直接当成穿线孔。外周同样紧张：皮带假设包络到 R102 井口名义约 3.5 mm，到停放托盘内端约 1.5 mm，均未计线束及装配误差。因此不能沿转运台外沿简单绑一圈线。

优先研究转运板下受保护的柔性回环空间，明确不旋转端和旋转端的固定夹、无扭转安装姿态、线缆弯曲/扭转要求及防夹护挡。**这只是待验证方向，当前模型没有证明放得下。** 若不足，需要调整安装高度或设计专用导线结构；改变高度时同步重核托盘对接高度、8 mm 啮合/脱开、层间净空和轴系连接，不能直接加垫后认为问题已解决。

转角仍限制为项目规定的 −135°～+180° 往返。软件路径不能为了“最短转角”跨越线束边界；断电后位置未知，也不能自动绕圈找原点。应检查每个高度下两个角度端点、八个工作方位及完整往返过程，而不只检查静止姿态。

现有 67.5° 拖链仅是空间占位：径向 130～152 mm、切向 ±7 mm、Z=40～250 mm。真实拖链的内腔、弯曲半径、弯头、端头和运动包络尚未确定，不能据此直接下单或定线长。

## 3. 电源应该怎样分支

```text
12 V 适配器 → 入口保险/总开关 → 配电端子
                               ├─ 逻辑支路 → 12→5 V 降压
                               │                ├─ 星火一号的已确认供电入口
                               │                ├─ 屏幕电源支路（电压待完整型号确认）
                               │                └─ 经 3.3 V 稳压/已确认板上输出 → 逻辑与传感器
                               └─ 电机支路 → K1 主触点 → 三块 TMC2209 的 VM

急停常闭 + Z 上/下硬限位常闭 → K1 控制回路
手动复位 + 自保持条件 → K1 恢复（不能松开急停即自动恢复）
```

上图为功能关系，不是继电器端子接线图。K1 线圈电压、直流触点额定值、触点数量、抑制器件及复位电路须按实际型号画出。普通继电器回路也不能直接宣称具有经认证的安全等级。

- 电机支路断电时，主控和屏幕保留电源，便于显示故障；各支路负极共地。电机电流经配电端子回电源，不能经过主控排针或传感器细线回流。
- 每块驱动附近配置适合其模块的储能、去耦和过压措施，相关电容与保护应留在 K1 之后的驱动侧。断开 VM 后的电容残留能量、减速回馈及实际停止距离需验证；不能把断电等同于瞬间静止。
- 硬限位回路和 MCU 监测分开。12 V 回路不能直接进 GPIO；采用独立干接点或经设计的电平/隔离接口。普通三脚 COM/NO/NC 开关的两种触点共享 COM，不等于两组隔离触点。
- 上下硬限位应在正常软限位之外动作；一旦硬限位切断电机电源，不提供软件自动旁路。排除故障、恢复机构位置后人工复位。
- 原方案 12 V/5 A、5 V/3 A 是候选规格。即使只允许一轴运动，其他轴也可能保持励磁，不能据此沿用“峰值约 2 A”作为实测结论。
- 先核对星火板供电入口和 USB 电源关系，再接外部降压电源。所查原理图的 P3、P4 标为电源输出，不能仅凭有 5 V 排针就认定可作推荐输入；开发板不能接 12 V。调试 USB 与外部供电并用时需核实防反灌路径。
- 3.3 V 可评估采用板上受保护输出，或另设稳压支路；两种稳压输出不能直接并联。需核对模块总电流、线损、上电顺序和主控关闭时的信号回灌。
- 升降停电保持仍以带载试验为准；任何急停设计均不能依赖尚未证明的丝杆自锁。

## 4. TMC2209 与三台电机怎么连接

初版采用 STEP/DIR 控制。UART 配置作为后续可选项，不是三台电机转起来的必要条件。先做单轴台架验证，再接入整机。

| 驱动信号名称 | 应接到哪里 | 备注 |
|---|---|---|
| VM / 电机电源端 | K1 后的 12 V 电机支路 | 不能接到逻辑电源端；以模块丝印为准 |
| GND | 配电地，并与 MCU 逻辑地相连 | 电源地和信号参考地都要有明确回路 |
| VIO / VCC_IO | 已确认的 3.3 V 逻辑电源 | 需核实红排针模块是否有板上固定连接 |
| STEP | 对应轴的 MCU 定时器输出 | Z、θ、U 各自独立 |
| DIR | 对应轴的 MCU GPIO | 方向在产生 STEP 前稳定 |
| EN / ENN | MCU 使能控制，外部上拉到 VIO | 低有效；复位/程序未启动时应禁用，不能悬空 |
| A 相两输出 | 电机同一绕组的两根线 | 先用万用表确认相对 |
| B 相两输出 | 电机另一绕组的两根线 | 不能按线色跨型号套用 |
| 模式脚、UART、DIAG 等 | 按实际模块及所选模式配置/预留 | 不照抄 A4988 接法；不能把不同版本模块的针序混用 |

共用 EN 可保留为初版选择，但要认识到它同时使能三块驱动；静止轴仍可能消耗保持电流。转接板可把三路 EN 各自引到端子，再决定共用或独立控制。独立禁用升降轴前必须先解决载荷保持问题。

本地规格书标注：28BL262.6-18Y 为 0.8 A/相，42BL4002-24A 为 1.7 A/相；它们不是已经核实的实物限流设定。尤其小电机不能直接照用驱动资料中的默认电流。TMC 的 RMS/峰值定义、实际采样电阻、VREF 关系和模块散热能力须一并核对，不能直接用 A4988 公式。

红排针资料包含多个模块示例。正式表应记录“模块丝印名称 → 转接板端子编号 → 电机插头编号”，不用“从左第几针”代替方向说明。插接、换相及调线均在断电并确认电容放电后进行。

## 5. 层板、霍尔、LED 与 DOCK

MCP23017 用 3.3 V；按厂商现行资料避开 GPA7/GPB7 输入用法。建议的一层完整分配如下：

| MCP23017 引脚 | 用途 | 方向 |
|---|---|---|
| GPA0～GPA6 | 七个停车位托盘霍尔 | 输入 |
| GPB0 | DOCK 托盘霍尔 | 输入 |
| GPA7 | DOCK 指示 LED | 输出 |
| GPB1～GPB7 | 七个停车位指示 LED | 输出 |

这样恰好满足一层 8 个霍尔 + 8 个 LED。两路 DOCK 光电改接 MCU 独立输入；车位状态可经 I²C 读取，但手进入检测不应只依靠层板轮询。最终防夹设计还需考虑光束覆盖、故障状态和停机距离，**把光电接到 MCU 不等于已实现安全防护**。

二层可沿用同一接口定义：GPA0～6 接 7 个霍尔，GPB1～7 接 7 个 LED，GPB0/GPA7 预留。地址采用 7 位表示：一层 0x20，二层 0x21；即一层 A2/A1/A0 全接低，二层只把 A0 接高。地址脚和 RESET 不能悬空。

连接方式：

- 霍尔按实物确认 VCC、GND、OUT，不按外观猜针序。开漏输出上拉到 3.3 V；若为推挽或模块自带上拉，需要核实输出电压，避免 5 V 输出直接进入 3.3 V 输入。
- DRV5032 有不同采样率和输出类型，具体尾码必须确认。车位静态检测与 θ 回零的响应要求不同，不能把低速采样型号直接用于精确回零而不评估速度和延迟。
- 每颗 LED 都需限流电阻，按正向压降及低毫安目标电流选取，并核对扩展器总电流；较大负载另加驱动器件，不从 GPIO 直接供电。
- 两路 DOCK 检测应在接口表中明确成两路独立输出及覆盖区域。采购中“一套对射光电”是否真的提供两路，尚待核实。
- 微动输入建议使用 COM/NC、3.3 V 外部上拉和适当滤波：正常闭合为低，触发或开路为高。开路可被发现，但这不覆盖短路等故障；滤波也不能把停机响应拖得过长。

层间总线功能线为 3.3 V / GND / SDA / SCL。一层、二层物理串接，电气上接在同一条 I²C 总线；不能把各模块当电气串联器件。先以 100 kHz 和短线验证，上拉只按全总线的合成阻值配置，检查模块自带上拉，避免全部并联后过强。电机动作时验证通信和上升沿；电源/地有线损也要实测。

最终线束可在 4 根功能线之外增加地回线或中断线；若新增 INTA/INTB，不能继续按 4P 插头计算。SDA、SCL 保持短支线并各有邻近地回路，避免与电机相线长距离紧贴。

## 6. 星火一号可优先考虑的接口

以下已对照本地原理图 PDF 第 3、9 页的连接器网络，并参考 ST 的引脚复用资料；**它们是候选，须与实物板卡修订版和后续固件配置核对后冻结**。本地文件名带 V1.0，但图框标为 HW1.1，不能用文件名代替实物版本。

| 用途 | MCU 引脚候选 | 原理图连接器位置 | 计划功能 |
|---|---|---|---|
| 层板 SDA | PB7 | P2 第 3 脚 | I2C1 SDA |
| 层板 SCL | PB6 | P2 第 5 脚 | I2C1 SCL |
| 主控发送到屏幕 RX | PB10 | CN6 / PMOD2 第 2 脚 | USART3 TX |
| 屏幕 TX 发给主控 | PB11 | CN6 / PMOD2 第 3 脚 | USART3 RX |
| Z STEP | PA8 | P2 第 7 脚 | TIM1 CH1 |
| θ STEP | PA0 | P2 第 12 脚 | TIM2 CH1 |
| U STEP | PD12 | CN6 / PMOD2 第 4 脚 | TIM4 CH1 |

注意：

- UART 的 TX 接对方 RX，并共地；屏幕电压与串口电平须分别确认，供电是 5 V 不代表 TX 一定输出 5 V，反之也不能默认是 3.3 V。
- USART3 在此用 PB10/PB11，不启用占用 PD12 的硬件流控；PD12 留给拨叉 STEP。
- 三个 STEP 使用不同定时器，便于独立频率与加减速；PB6/PB7 已分给 I²C，不再给它们分配 TIM4 输出。
- USART1 保留作板载调试串口；DIR、EN、10 路基础状态输入（Z 回零、Z 上下监测、θ 原点、U 两端、台上托盘、急停状态、两路 DOCK 光电）仍需补完整 GPIO 表，并根据 EXTI 通道冲突选中断引脚。
- 未见本项目固件，因此没有声称 BSP 已启用这些接口。现有板载器件、扩展模块、引脚复用和初始化都要与最终表一致；连接器编号须对实物 1 脚标记确认。

## 7. 线束与连接器初版清单

下表定义功能分组，不冻结成品长度、线径或接头型号。所有活动线需选适合实际弯曲/扭转方式的线材，并用线夹承受拉力；插头、焊点不能承担机械拉力。

| 编号 | 起点 → 终点 | 线束功能 | 路径 |
|---|---|---|---|
| P01 | 12 V 入口 → 配电端子 | 正、负电源 | 底座固定 |
| P02 | 电机配电 → 三块驱动 | 各自 VM/GND 分支 | 底座固定 |
| MZ | Z 驱动 → 升降电机 | 4 根相线 | 底座固定 |
| MT | θ 驱动 → 旋转电机 | 4 根相线 | 竖向拖链，到升降平台结束 |
| MU | U 驱动 → 拨叉电机 | 4 根相线 | 竖向拖链 + 旋转柔性连接 |
| ST | 主控 → θ 原点霍尔 | 电源、地、输出 | 竖向拖链，到不旋转安装侧 |
| SU | 主控 → 旋转台检测分线点 | 3.3 V、GND、U 收回、U 伸出、托盘霍尔；可用 6 芯留 1 芯备用 | 竖向拖链 + 旋转柔性连接；以无源微动和 3.3 V 霍尔为前提 |
| L01/L12 | 主控 → 一层 → 二层 | I²C 及供电 | 固定外框立柱 |
| DZ | 电控区 → Z 检测 | 回零、上下监测；硬限位回路另列 | 固定塔架，按实际开关位置分别引线 |
| DK | 主控 → DOCK 检测 | 两路光电的电源及输出 | 固定前框，避开用户出入口 |
| HMI | 主控/电源 → 串口屏 | RX/TX/GND 及对应电源 | 固定外框；针数随屏幕版本决定 |
| ES | 急停/硬限位/复位 → K1 | 硬件控制回路；监测接口另列 | 固定走线，与逻辑端子清楚区分 |

电机每一相的两根线成对布置，不能把 A 相和 B 相各取一根配成对。电机/电源线与霍尔、开关、通信线分束；同进拖链时考虑分隔和地回路，不将全部线随意绞成一束。

正式连接优先选有锁扣、适当额定电流和防插错方式的插接件/端子。杜邦跳线适合桌面验证，活动线束与电机电源连接需更可靠的固定。线径应由实际电流、长度、压降、成束温升及接头额定值共同确定，本次不凭预算表定线径或保险丝值。

两端使用相同线号，标注电压、轴名和连接器编号；线色只是辅助。所有穿板处设护口并磨除锐边。长度应在最低/最高位置和完整旋转范围实配后确定，不能只在一个姿态量直线距离。

## 8. 落地顺序与验收

1. **确认实物身份和接口**：星火板版本及 1 脚、TMC 两面丝印/跳线、三台电机铭牌和相对、屏完整后缀、传感器尾码及输出、急停/限位/继电器触点。没有这些，不冻结插头针序和限流。
2. **优先试配活动线束**：用实际外径的线材验证旋转连接、拖链、分线点和固定夹，补齐 Z 回零/监测安装点。需要修改机械时先改结构，再裁最终线长。
3. **完成逐针接线表和整机原理图**：每行写起点针号、终点针号、信号名、电压、线号和动作状态，同时完成 K1 自保持/复位、输入调理及供电防反灌设计。
4. **仅接逻辑部分验证**：测各电源、主控启动、屏通信、MCP 地址及每个输入状态；验证输入开路行为和 LED 限流。先不使能电机。
5. **单轴低速验证**：断电配对相线，按实物调限流；在可控台架或支撑好升降平台的条件下测方向、温升、回零/限位、默认禁用和停止响应。
6. **整机低速空载，再带载**：测最高/最低、八方位、拨叉全程、托盘跨缝和完整往返中的线缆状态；测试急停、限位、重启不自启动、最高位断电保持。再做重复循环及电源/通信抗干扰检查。

本次已完成资料层面的连接关系核对和明显冲突排查；以上实物验收均未执行。最终交付应至少包含电源/急停图、逐针接线表、物理走线图与线束表四部分。
