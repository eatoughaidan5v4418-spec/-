## 1 项目概述与需求分析

### 1.1 项目背景

城市停车位紧缺推动立体车库向更高空间利用率发展。传统多层车库常在停车区外侧另设横移或回转跑道，导致外轮廓大于有效停车区，占用额外建筑面宽与进深。本作品针对“外挂跑道占空间、样机调度难验证、扩展性差”等问题，提出一种**华容道式层内滑移 + 升降对接**的紧凑立体车库调度系统：停车层内以华容道规则滑移车辆托盘，外框不外挂横移跑道，外轮廓等于停车区；存取车人机操作仅在下层共用升降对接口（DOCK）完成，由调度软件自动把空位或目标车滑移至对接口后再升降交接。

### 1.2 需求摘要

| 需求类别 | 具体要求 |
|----------|----------|
| 结构紧凑 | 外轮廓等于停车区；不外挂横移跑道；层内华容道滑移 |
| 样机规模 | 两层；每层 2×2 布局并留 1 空位（满载 3 车/层）；结构/坐标预留扩展至 3×3 |
| 人机边界 | 用户仅在下层 DOCK 放车/取车；不设上层人工存取接口 |
| 安全 | 急停只切断电机电源轨；逻辑与主控保持供电；限位联锁；任务可抢占 |
| 调度 | 坐标 (层, 行, 列)；优先级：急停 > 取车 > 存车；存取前先将空位/目标车滑至对接口 |
| 平台约束 | 星火1号 / STM32F407；必须采用 RT-Thread 标准版 |
| 演示 | 可现场演示存车、取车、急停与联锁；配套说明视频建议 ≤5 分钟 |

### 1.3 设计目标

1. 完成两层 2×2（每层留 1 空）样机的机械联动与电气联锁，证明“外轮廓=停车区”的华容道紧凑布局可行。  
2. 在 RT-Thread 上实现可抢占任务队列与安全联锁，保证急停与取车相对存车的优先级。  
3. 采用统一坐标调度，软件与结构均预留扩展至 3×3，避免硬编码死格子。  
4. 人机界面以淘晶驰 4.3 寸串口屏为主，流程清晰可演示。

## 2 单片机参数与选型

### 2.1 主控芯片主要参数（STM32F407）

| 参数项 | 指标 |
|--------|------|
| 内核 | ARM Cortex-M4，带 FPU |
| 主频 | 最高 168 MHz |
| Flash / SRAM | 典型 1 MB Flash / 192 KB SRAM（视具体料号） |
| 定时器 | 多路通用/高级定时器，便于步进细分脉冲与电机 PWM |
| 通信接口 | 多路 USART、I²C、SPI；满足串口屏、PCA9685、MCP23017 等外设 |
| GPIO | 丰富，可挂接限位扩展与电机方向/使能脚 |
| 调试 | SWD，便于 RT-Thread 联调 |
| 生态 | 官方与社区资料完善；与 RT-Thread 适配成熟 |

### 2.2 为何选择星火1号 / STM32F407

1. **算力与接口余量**：华容道调度需维护车位表、任务队列与多轴联锁状态；F407 主频与 SRAM 相对 F1/F0 更充裕，便于运行 RT-Thread 标准版及多线程。  
2. **外设匹配**：USART2 直连淘晶驰串口屏；I²C 可挂 PCA9685（托盘电机 PWM）与 MCP23017（限位扩展）；定时器资源满足升降步进脉冲生成。  
3. **性价比与可获得性**：主控板按二手预算 **≤240 元（人民币）** 选型采购；星火1号/同类 F407 开发板二手市场常见、引脚引出完整，性价比优于同档全新工控板。  
4. **赛项契合**：方向三强调单片机应用；F407 + RT-Thread 可体现实时调度与工程化线程划分，而不依赖 PC 上位机做核心控制。

### 2.3 为何必须采用 RT-Thread 标准版

| 对比点 | 裸机主循环 | RT-Thread 标准版（本方案） |
|--------|------------|----------------------------|
| 任务形态 | 轮询易阻塞 | 多线程：人机、调度、运动、安全监测可解耦 |
| 优先级 | 难做抢占 | 支持线程优先级与可抢占任务队列（急停/取车优先） |
| 外设驱动 | 自行堆叠 | 组件与设备框架便于 USART、I²C 设备化 |
| 调试与工程 | 结构易散 | 推荐使用 **RT-Thread Studio** 工程化构建与调试 |
| 赛项要求 | — | **必须使用 RT-Thread 标准版** |

结论：以星火1号（STM32F407）为硬件载体，软件平台固定为 **RT-Thread 标准版**，开发环境推荐 RT-Thread Studio。

## 3 硬件规划

### 3.1 系统组成（文字框图）

墙上 **220 V AC → 12 V** 适配器进入机内后分为两路电源轨：  

- **逻辑轨**：始终供给主控（星火1号/F407）、串口屏、I²C 扩展（PCA9685、MCP23017）及信号电路；急停**不断**此轨。  
- **电机轨**：经急停继电器/接触器供给升降步进驱动（A4988）与托盘直流电机驱动（TB6612）；急停**只断电机轨**。  

主控通过：USART2 连接淘晶驰 4.3 寸电阻串口屏；I²C 连接 PCA9685（驱动 6 路 N20 托盘电机经 TB6612）与 MCP23017（限位输入扩展）；GPIO/定时器连接 A4988 控制 1 台 NEMA17 升降电机。板载小屏仅作调试辅助，**不做主界面**。机械上两层托盘阵列按华容道规则层内滑移，前侧共用升降对接口与下层 DOCK 人机位对接。

### 3.2 电源与急停策略

| 项目 | 方案 |
|------|------|
| 输入 | 墙上 220 V → 12 V 适配器；机内全低压 |
| 逻辑供电 | 12 V 经稳压至 5 V / 3.3 V 供主控、屏、逻辑芯片 |
| 电机供电 | 12 V 电机轨 → A4988 / TB6612 |
| 急停 | 硬件切断电机轨；主控与人机逻辑保持运行，可检测急停状态并清空/挂起运动任务 |
| 恢复 | 急停解除后需人机确认，再允许新的存取任务，避免误动作 |

### 3.3 主控与外设清单

| 类别 | 型号/规格 | 数量 | 作用 |
|------|-----------|------|------|
| 主控板 | 星火1号 / STM32F407（二手预算 ≤240 元） | 1 | 调度、联锁、通信 |
| OS | RT-Thread 标准版 | — | 多线程与可抢占调度 |
| 人机屏 | 淘晶驰 TJC4827T143，4.3 寸电阻串口屏，5 V | 1 | 主界面：存车/取车/状态/急停提示 |
| 升降电机 | NEMA17 步进 | 1 | 托盘/载具层间升降 |
| 升降驱动 | A4988 | 1 | 步进脉冲与方向控制 |
| 托盘电机 | N20 减速直流电机 | 6 | 层内华容道滑移（两层托盘阵列） |
| 托盘驱动 | TB6612 | 按通道配置 | N20 正反转与刹车 |
| PWM 扩展 | PCA9685 | 1 | I²C 多路 PWM 控制 TB6612 |
| 限位扩展 | MCP23017 | 1（可按点位扩展） | I²C GPIO 扩展采集限位 |
| 急停 | 急停按钮 + 电机轨切断器件 | 1 套 | 只断电机电源 |
| 电源 | 220 V→12 V 适配器 + 机内稳压 | 1 套 | 全机低压供电 |

### 3.4 关键器与接线要点

#### 3.4.1 升降轴

- 1× NEMA17 + 1× A4988。  
- 主控定时器输出 STEP，GPIO 输出 DIR/ENABLE；ENABLE 与急停联锁逻辑配合（电机轨断电时即使逻辑脚状态异常也不产生运动）。  
- 行程两端（及必要时中间对接位）经 MCP23017 或直接 GPIO 采集限位，运动前/中校验。

#### 3.4.2 托盘层内滑移

- 共 6× N20 + TB6612，PWM/方向由 PCA9685（I²C）统一产生。  
- 每层 2×2 留 1 空，满载 3 车/层；滑移遵循华容道“向空位挪移”规则。  
- 各滑移终点设限位，经 MCP23017 汇总，防止越界与卡死硬顶。

#### 3.4.3 人机屏

- 型号：TJC4827T143；接口：USART2（PA2/PA3）；供电：5 V。  
- 作为唯一主操作界面：选车位/确认存取、显示坐标与任务状态、急停与故障提示。  
- 板载小屏不承担主流程 UI。

#### 3.4.4 限位与扩展

- MCP23017 扩展限位与部分开关量输入，减轻 F407 直连引脚压力，便于 2×2 样机向 3×3 增加点位时少改主板布线。

### 3.5 DOCK 人机边界

| 约定 | 说明 |
|------|------|
| 唯一人工口 | **仅下层 DOCK** 允许用户放车、取车 |
| 上层 | 无人工存取接口；上层车辆仅通过升降 + 层内滑移周转 |
| 对接口 | 前侧共用升降对接口；存取前调度必须先将空位（存车）或目标车（取车）滑移至对接口列/位 |
| 安全 | DOCK 有车/无车、升降未到位时禁止相冲动作；由限位与软件联锁共同保证 |

## 4 设计方案

### 4.1 总体架构

系统分为四层：  

1. **人机层**：串口屏指令与状态回显；  
2. **调度层**：车位表、任务队列、优先级与华容道路径规划（坐标级）；  
3. **运动层**：升降步进序列、层内 N20 滑移序列、限位确认；  
4. **安全层**：急停检测、电机使能联锁、非法状态拒绝执行。  

硬件上外框不外挂横移跑道；软件上以坐标调度驱动层内滑移与升降对接，形成“结构紧凑 + 调度可验证”的闭环。

### 4.2 坐标与 DOCK 定义

- 车位坐标统一为 **(层, 行, 列)**。  
- 样机：层 ∈ {1, 2}；每层行×列 = 2×2，且每层恰好保留 1 个空位（满载 3 车/层）。  
- **DOCK**：固定映射为下层前侧对接口对应坐标（与升降对接位对齐）；用户只在此放车/取车。  
- 结构件安装孔位与软件坐标枚举**预留扩展到 3×3**，避免后期推翻机械基准。

### 4.3 存车 / 取车流程（大纲）

**存车（用户只在下层 DOCK）：**

1. 用户在 DOCK 放车并在屏上确认存车；  
2. 调度检查目标层空位；若对接口当前被占，先按华容道规则将空位滑至对接口；  
3. 升降对接，将车辆送入目标层托盘体系；  
4. 层内滑移，把新车安置到规划车位，并保证该层仍留 1 空；  
5. 更新车位表，屏显完成。

**取车：**

1. 用户在屏上选择目标车（坐标或车位号）；  
2. 调度将目标车经层内华容道滑移送至对接口；必要时先升降到对应层再滑移；  
3. 升降至下层 DOCK；  
4. 用户取车；更新车位表。

**共同点：** 任何存取执行前，必须先把**空位或目标车**滑到对接口相关位置；升降与层内滑移互斥，由联锁状态机约束。

### 4.4 调度、优先级与防死锁（从简）

| 规则 | 内容 |
|------|------|
| 优先级 | **急停 > 取车 > 存车** |
| 可抢占 | 高优先级任务可抢占低优先级队列任务；被抢占任务安全中止或回滚到限位确认的稳态 |
| 空位策略 | 每层维持至少 1 空；滑移步序只允许移入空位，避免两车对顶 |
| 防死锁 | 规划时检测层内连通与空位可达；不可达则改选过渡步或拒绝任务并提示，不盲动 |
| 急停 | 断电机轨 + 软件冻结运动线程；恢复需人工确认 |

### 4.5 RT-Thread 线程划分（大纲级）

| 线程（逻辑名） | 职责概要 | 相对优先级意向 |
|----------------|----------|----------------|
| 安全监测线程 | 急停、关键限位、电机轨状态 | 最高 |
| 调度线程 | 任务队列、优先级、华容道路径与车位表 | 高 |
| 运动执行线程 | 升降/滑移节拍、到位确认 | 中 |
| 人机通信线程 | USART2 屏协议解析与界面刷新 | 中低 |
| 空闲/统计 | 心跳、简易日志 | 最低 |

说明：仅给出划分与优先级意向，不在计划书展开大段伪代码；实现阶段在 RT-Thread Studio 中落地信号量/互斥与事件。

## 5 创新点

创新点均按「问题 → 做法 → 可验证效果」表述。

### 5.1 创新点①：外轮廓等于停车区的华容道紧凑布局（不外挂跑道）

- **问题**：常规立体库在停车区外另设横移跑道，外轮廓大于有效车位区，样机与落地场景均浪费面宽。  
- **做法**：层内按华容道规则滑移托盘，前侧共用升降对接口；外框不外挂横移跑道，外轮廓对齐停车区；样机两层 2×2 留 1 空验证。  
- **可验证效果**：外观与图纸上外轮廓与停车阵列一致；演示全程无外挂跑道参与横移；同等占地可摆放的有效车位数优于“外挂跑道”对照叙述。

### 5.2 创新点②：可抢占任务队列 + 安全联锁

- **问题**：存车长流程若不可抢占，取车等待过久；急停若只靠软件停 PWM，电机轨仍带电存在风险。  
- **做法**：RT-Thread 上实现带优先级的可抢占任务队列（急停 > 取车 > 存车）；硬件急停只断电机轨，逻辑与主控不断电并继续监测；运动与升降/滑移互斥联锁。  
- **可验证效果**：演示中途插入取车可打断存车排队；按下急停后电机立即失电且界面进入安全态；解除后需确认才继续，无自启动。

### 5.3 创新点③：坐标化调度，结构预留扩展到 3×3

- **问题**：按 2×2 写死车位号导致扩容需改大量逻辑与机械基准。  
- **做法**：统一坐标 (层, 行, 列) 描述车位与 DOCK；调度与华容道推演基于坐标与空位；机械安装与限位编号预留 3×3。  
- **可验证效果**：文档与程序中车位均以坐标访问；展示预留孔位/接口与坐标枚举扩展点；将尺寸参数改为 3×3 时调度框架无需推倒重来（样机硬件仍为 2×2 验证）。

### 5.4 （可选）创新点④：掉电车位表自检恢复

- **问题**：掉电后内存车位表丢失，上电误判易撞车。  
- **做法（可选）**：关键车位表掉电保存；上电后结合限位/自检行程校验空位与占用一致性，不一致则进入维护提示。  
- **可验证效果**：掉电再上电后车位显示与实际一致，或明确报出不一致并禁止自动存取。  
- **说明**：本项标为可选增强，初赛以①②③为必述创新点。

### 7.2 风险与对策

| 风险 | 对策 |
|------|------|
| 层内卡死/摩擦偏大 | 限位分步确认；降低 N20 占空比；机械导轨复检 |
