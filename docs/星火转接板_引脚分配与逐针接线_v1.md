# 星火一号转接板：引脚分配、XH接口与逐针接线 v1

日期：2026-11-07。用途：原理图绘制输入，可先据此建符号、网络及接口；并非已通过实物验证的可直接投板文件。

## 1. 本版设计边界

依据本地星火原理图的 PDF 第3页（MCU）和第9页（扩展口）核对。原理图文件名 V1.0，图框为 HW1.1；须与实物修订版一致。三轴采用独立 STEP/DIR/EN，驱动模块仍独立安装；本板不承载12V电机配电、驱动功率输出及电机四相线。屏和光电完整型号、原配线序尚未全部确认，因此下面的XH针序是**新板设计定义**，不是对现有线束针序的实测结论。

先画完整的P2、PMOD1、PMOD2、Spark-10P原始接口转出，再由这些网络分支接功能口。另预留P5外接RGB接口转出。USB、CAN/RS485收发器输出和P3/P4重复电源口不纳入本版“GPIO全部引出”；保留星火原有接口使用。Spark-10P的PE6不在PMOD1上，若要连PE6，必须实际接入P1。

## 2. 电源网络必须区分

| 网络 | 来源/连接 | 本版处理 |
| --- | --- | --- |
| V3P3_OUT | 星火P2.1、P2.17 | 板上受控/受保护输出；经JP3供本板VLOGIC_3V3。容量需核算 |
| V3P3_CORE | CN5.6/12、CN6.6/12、P1.10 | 星火内部3.3V；仅原样转出，不与V3P3_OUT在转接板上短接 |
| VLOGIC_3V3 | JP3从V3P3_OUT取电 | 驱动VIO、层板、3.3V传感器、输入上拉；JP3可断开便于量电流 |
| V5_SYS | 星火P2.2、P2.4、P5.1 | 仅原样转出；不默认用它供整块屏 |
| V5_EXT | 单独2P螺丝端子J200.1，J200.2=GND | 外部合规5V降压电源；不与V5_SYS硬并联，不经本板向星火反向供电 |
| VHMI | 独立选配焊桥从V5_EXT或经核算的3.3V支路取电 | 两路选一，默认均不装；核实屏型号/电压后确定 |
| GND | P2固定地脚与外部逻辑电源负端 | 共参考地；电机大电流回流不经过本板信号地 |

不在本板上把不同稳压器的输出直接并联。VLOGIC未验证负载前，不保证板上3.3V能供全部外设；需要独立稳压时另做电源选择和上下电回灌校核。星火自身仍使用已确认的供电入口。

## 3. 原始接口逐针转出

编号以下均是**原理图引脚号**，不是按照片从左到右数。J001~J005为接星火的一侧，R001~R005为本板向外保留的调试接口；默认逐针同号、同网转出。

P2按奇偶两列编号；PMOD按一列1~6、另一列7~12编号。不要把PMOD直接画成普通奇偶编号的2×6符号而不改引脚映射。连接线、PCB顶面/底面和插头观察方向可能镜像，以封装焊盘号、实际1脚标志和导通测量为准。

23个功能网络对应23个不同MCU引脚；10路检测分别使用EXTI0~9。EXTI5~9仍共用中断向量，ISR要逐一检查标志；同编号EXTI不能同时映射到另一个端口。板载按键PC0/PC1/PC4/PC5若配置EXTI，会与本表相应通道冲突，固件应关闭这些按键中断或改为轮询。没有本项目固件，本表不代表BSP已完成配置。

TIM1、TIM2、TIM4用于三轴脉冲；不能再把它们的其他通道当成可任意设置独立周期的定时器使用。USART3仅PB10/PB11，不启用CTS/RTS及同步时钟；PD8/PD9/PD10保持本表GPIO模式。保留板载USART1调试，不挪用SWD、LCD、SD及板载传感器专用网络。

## 5. XH接口数量及逐针接线

所有针号由所选连接器数据手册的pin 1标识定义；丝印标注1脚和电压。以下外设电源均按3.3V兼容模块设计。屏及光电若实际需要其他电源/电平，应先改该接口电源或加调理，不可只改线色就直连。

| 针数 | 接口编号 | 数量 |
| --- | --- | --- |
| 2P | J130, J131, J132, J133, J150, J151 | 6 |
| 3P | J140, J141, J142, J143 | 4 |
| 4P | J110, J120, J121 | 3 |
| 5P | J101, J102, J103 | 3 |
| 6P | J160 | 1 |

**全预留共17个XH插座、57个针位。** J121为并联备用口，J160为组合线束选项。若只装组合口J160，可不装J141/J150/J151，装配数变14；再不装备用口J121则为13。推荐原理图先全预留，按线束选装。J141/J150/J151与J160对应信号电气并联，不是新输入，禁止接上两套不同传感器驱动同一信号。

## 6. 输入与输出外围怎么画

### 6.1 三轴驱动

J101~J103每路EN_N对VLOGIC_3V3加10kΩ上拉，驱动端也应有可靠默认禁用状态；STEP/DIR可留33~100Ω串联电阻位置，走线短、带连续地参考。上电先保持EN高，配置GPIO和细分/电流后才允许使能。升降轴失能是否下滑必须实测，不能仅靠上拉解决载荷保持。

这三个5P是本板自定义控制接口，红排针TMC模块本身不是5P XH接口：另一端需要配套底座或小转接线，按模块丝印把VIO/GND/STEP/DIR/EN逐根接上。驱动VM、动力GND和A/B相输出留在独立驱动/配电部分。PDN/UART、MS模式脚按该模块选定模式处理，不允许照搬A4988跳线；本版不分配TMC UART或DIAG。

### 6.2 无源开关及传感器输入

每个输入可画：XH信号端 → 1kΩ串联电阻 → 对应MCU网络；在MCU侧预留10kΩ上拉到VLOGIC_3V3和10nF到GND的电容。无源NC触点默认装上拉；电容默认不装，实测干扰与回零响应后决定。传感器上拉是否装配取决于开漏/推挽及模块已有电阻，不能一律重复装。

同一个输入只装一套上拉/滤波，J160和其分立替代口不能重复装两套。滤波参数只是调试起点，需核对实际输入阈值、输出灌电流和停机/回零延时。

J133只接独立无源辅助触点，不能接带12V的继电器线圈端或急停动力回路；没有独立辅助触点时需另画合适的隔离/电平调理。Z两只硬限位切断电机支路的触点仍走独立硬件回路，J131/J132接另外的监测触点/开关。两路DOCK检测仍需核对实际传感器是否独立输出，不能用同一根OUT并接两路来冒充两路检测。

### 6.3 屏幕

J110.1=VHMI由焊桥选择电源，默认不装。PB10 → R_HMI_TX → HMI_TO_SCREEN_RX；HMI_FROM_SCREEN_TX → R_HMI_RX → PB11，两个0Ω位置默认不装，另在两侧留测试焊盘/适配焊盘。核对屏幕TTL电平并确认可直连时再装0Ω，否则通过对应方向的电平转换器连接。不能把TTL口接到RS232或RS485，也不因屏供电5V就推断串口电平。

这使未确认屏幕规格时仍可先画好原理图与接口，而不会在默认装配中把未知电压直接送进MCU。原配屏线若不是本表顺序，应按设备丝印做转接或修改本板J110针序，并同步改表；不要靠“红黑黄蓝”等颜色推断。

### 6.4 I²C与电源去耦

SDA/SCL各预留一只4.7kΩ上拉到VLOGIC_3V3，默认不装，按星火/层板/模块的实际并联上拉计算后装配。先100kHz、短线验证。每个供电接口附近预留100nF，逻辑电源入口留10µF；屏供电电容与线径按屏启动和背光电流核定。J120/J121并联在同一总线，不是隔离总线。第二层优先从第一层固定分线点菊链接入。

## 7. 层板MCP23017逐针功能表

本板J120通过四根功能线到层板，8个车位/DOCK霍尔不直接全部回到主转接板。层板另画下列接口；这部分数量不计入上面的17个。

| 层板接口 | 针序 | MCP端口 | 用途 |
| --- | --- | --- | --- |
| LH01 | 3P：1=3.3V，2=GND，3=OUT | GPA0 | 七个停车位中的第1位；方位编号按实际安装标定 |
| LH02 | 3P：1=3.3V，2=GND，3=OUT | GPA1 | 七个停车位中的第2位；方位编号按实际安装标定 |
| LH03 | 3P：1=3.3V，2=GND，3=OUT | GPA2 | 七个停车位中的第3位；方位编号按实际安装标定 |
| LH04 | 3P：1=3.3V，2=GND，3=OUT | GPA3 | 七个停车位中的第4位；方位编号按实际安装标定 |
| LH05 | 3P：1=3.3V，2=GND，3=OUT | GPA4 | 七个停车位中的第5位；方位编号按实际安装标定 |
| LH06 | 3P：1=3.3V，2=GND，3=OUT | GPA5 | 七个停车位中的第6位；方位编号按实际安装标定 |
| LH07 | 3P：1=3.3V，2=GND，3=OUT | GPA6 | 七个停车位中的第7位；方位编号按实际安装标定 |
| LH08 | 3P：1=3.3V，2=GND，3=OUT | GPB0 | DOCK托盘检测 |

LED建议：DOCK用GPA7，七个停车位用GPB1~GPB7，每颗串限流电阻；GPA7/GPB7不作输入。一层A2/A1/A0=000，7位地址0x20；二层=001，地址0x21。MCP供电3.3V，RESET上拉并留复位点、地址脚固定。此处端口名是芯片逻辑端口，模块排针或裸芯片物理脚号按所选封装/模块原理图另行对应，不能跨封装套数字脚号。

一层层板另需8个XH3P霍尔口；总线入口1个XH4P，建议再预留1个XH4P给第二层。若把8个LED也做可拔插，各增加1个XH2P。即层板基础为3P×8、4P×2（含级联口），LED可选2P×8。主板17口 + 层板基础10口 = 整套27个XH，未计驱动独立底座、电机原插头、光电发射端和可选LED。

## 8. 画图后必须做的检查

1. 根据实物星火版本复核P2、CN5、CN6、P1的1脚和针序；PMOD封装编号与实际机械方向逐脚对应，不以普通2×6的默认编号代替。
2. 原始转出头只增加接点，不增加GPIO。已分配脚在保留头上仍可测量，但不能再接冲突外设。P2.14/30按独立配置网络转出，V3P3_CORE/V3P3_OUT分开。
3. 核对屏完整型号、霍尔及光电供电和OUT电平、现有XH线序。对未确认的电源选择/串口直连默认不装，确定后更新本表。
4. 接插件按实际XH尺寸选封装，保留拔插与固定空间。主连接器不同时刚性插入多组不同朝向插座，未核实板卡尺寸前PMOD可用短线连接。
5. 核对3.3V电流预算、外部5V与USB的上下电顺序及回灌；本表不保证原板能带所有外设。
6. 原理图ERC、PCB DRC、逐针导通/相邻短路测试、仅逻辑上电测试后，再做三轴及整机验证。没有完成这些前不称为已验证接线图。

已核对：原理图扩展接口与MCU网络、基础复用、功能GPIO不重复及EXTI编号不重复、接口针数和层板数量。未核对：实物修订版、现有线束逐针导通、厂商封装、实际电源负载/屏电平、固件初始化、实板上电。本文件没有生成PCB或可投板Gerber。
