# 星火1号塔式车库 HMI

一层样机的板载屏幕界面。平台是星火1号（STM32F407）+ RT-Thread + LVGL 8.3，屏 240×240，没有触摸。调度规则按硬件方案 v3 的演示子集来做：中央升降、旋转、拨叉；8 个方位里南侧是对接位，其余 7 个才是车位。

这里的车位表是演示初值，不是霍尔或光电的读数。运动过程只推进画面，不驱动电机。

## 页面

```text
待机 IDLE
  任意键
    └─ 命令甲板 MENU
         ├─ 存车 ── 对接提示 PARK/DOCK ── 选择空位 PARK/PICK ── 进度 PROG
         ├─ 取车 ── 选择车辆 GET ── 进度 PROG
         ├─ 驶离（仅对接位有车）── 托盘留在对接位，高亮回到存车
         └─ 待命（对接位无车）── 回到待机
         条件不满足时进入故障 FAULT，而不是静默失败
```

进度页在动作提交前不改车位表。存车完成后会短暂停在「已完成」，然后自己回到甲板。取车完成后停在「请取车」，等按键确认驶离或稍后处理。

待机、甲板、存车、取车、故障在 15 秒没有按键时回到待机。进度页不超时。已经调到对接位的托盘会留下，取消存车也是这样。

## 按键

低电平有效，内部上拉。同一时刻只认一个键，优先级是左、右、上、下。按下约 60 ms 后触发一次，不连发。

| 键 | 引脚 | 待机 | 甲板 | 存车 | 取车 | 进度中 | 进度完成 | 故障 |
|----|------|------|------|------|------|--------|----------|------|
| 上 | PC5 | 打开甲板 | 上一项，到顶不再循环 | 对接页无效；选位页上一个空位 | 上一辆 | 无效，提示作业中 | 存车：回甲板；取车：无效 | 无效 |
| 下 | PC1 | 打开甲板 | 下一项，到底不再循环 | 对接页无效；选位页下一个空位 | 下一辆 | 同上 | 同上 | 无效 |
| 右 | PC4 | 打开甲板 | 确认当前项 | 对接页进入选位；选位页开始 | 开始取车 | 无效 | 存车：回甲板；取车：确认驶离，托盘留在对接位 | 执行可恢复动作 |
| 左 | PC0 | 打开甲板 | 回待机 | 选位页退回对接提示；对接页回甲板 | 回甲板 | 中止，车位表回到动作开始前 | 回甲板。取车时车还停在对接位 | 回甲板 |

到顶、到底、无效、作业中会在底栏亮约 0.7 秒，然后恢复原来的提示。

## 车位环

方位从东开始顺时针，屏幕下方是南侧对接位，对着操作者：

| 序号 | 环上位置 | 短名 | 中文 |
|------|----------|------|------|
| 0 | 右 | E | 东 |
| 1 | 右上 | NE | 东北 |
| 2 | 上 | N | 北 |
| 3 | 左上 | NW | 西北 |
| 4 | 左 | W | 西 |
| 5 | 左下 | SW | 西南 |
| 6 | 下，方框 | DK | 对接 |
| 7 | 右下 | SE | 东南 |

颜色和字一起看：

| 样子 | 含义 |
|------|------|
| 灰底圆角，字母偏暗 | 空位，没有托盘 |
| 蓝底 | 空托盘 |
| 绿底 | 有车（车在托盘上） |
| 琥珀色方框 | 对接位。框内颜色仍表示空、盘或车 |
| 整格琥珀色 | 当前选中或本步正在处理的位置 |

待机中心的大数字是空位数，不含对接位。底栏 `空 / 盘 / 车 / 接` 也按这个口径。对接位上的车不算「在库」。

上电演示初值：东盘、东北车、北盘、西北空、西车、西南盘、对接盘、东南空。在库 2，空位 2，库内托盘 3，对接位已有托盘。

空位和空托盘的优先顺序都是：东南、西南、东、西、东北、西北、北。这是演示用的近对接位顺序，不是两层代价函数。

## 存车

1. 对接位有车：故障 E02。右键表示车已开走，托盘留在对接位，回到甲板并高亮存车。
2. 对接位没有托盘：从库内调一块空托盘过来。调完再取消，托盘仍留在对接位。
3. 库内没有空托盘：故障 E03。若库内有车，右键改去取车。
4. 对接位已有托盘但没有空位：故障 E01。这时对接托盘也没有空位可退，取车同样做不了，只能左键返回。
5. 对接提示页确认车已停好，再上下选择空位，右键开始。
6. 进度四步和环上高亮同步：旋转对准对接 → 拨叉拖入载车 → 转至目标 → 推入并脱开。进度环按百分比走。
7. 完成后目标位变成有车。若库内还有空托盘，调到对接位预置；没有则对接位空出。
8. 左键中止时，车位表恢复到按下开始之前，包括对接位仍是托盘。

## 取车

1. 对接位有车：E02，先确认驶离。
2. 库内无车：E04。右键改去存车。
3. 对接位有托盘但没有空位可退：E05。左键返回。
4. 列表只含库内有车的方位，从东边起跳过对接位。上下到头就停住。
5. 对接位若有托盘，进度先把它送回最近的空位，再对准、取出、送达对接位。
6. 对接位本来是空的，则直接旋转对准、升降啮合、拨叉取出、送达。
7. 完成后车在对接位。右键确认驶离，托盘留下；左键稍后，车先留在对接位。这一页不自动消失。

## 故障

| 代码 | 标题 | 含义 | 右键 |
|------|------|------|------|
| E01 | 无空车位 | 七个车位都占着，对接位的托盘退不回去 | 无。左键返回 |
| E02 | 对接有车 | 车还停在对接位 | 确认已驶离 |
| E03 | 无空托盘 | 没有可调来接车的空托盘 | 有车则改去取车 |
| E04 | 库内无车 | 没有可取的车 | 改去存车 |
| E05 | 无法暂存 | 取车前必须先挪走对接托盘，但没有空位 | 无。左键返回 |

## 烧录

本目录不是完整的 RT-Thread 工程。星火1号的内核、`packages/LVGL`、板级驱动和 LCD 驱动要从官方 LVGL 例程拿，不要在这个仓库里补一套。

1. 用 RT-Thread Studio 安装资源包 `STM32F407-RT-SPARK`，打开例程 `projects/06_demo_lvgl`（或板卡资料里等价的 LVGL 例程）。
2. 用本目录的 `applications/lvgl` 覆盖例程里的 `applications/lvgl`。`applications/SConscript` 和 `main.c` 保持例程原样即可；`main` 不初始化界面。
3. 确认编译时能先找到本目录的 `lv_conf.h`。需要打开 `BSP_USING_LVGL`、`BSP_USING_LVGL_DEMO`，LVGL 包版本与例程一致（本参考配置是 8.3）。`LV_MEM_SIZE` 是 96 KB：六个页面一直留在内存里，64 KB 时画进度环会分不到遮罩缓冲，界面卡死。不要改回例程里的 48 KB。参考宏在上一级的 `rtconfig.h`，那是例程配置摘录，不要把它当成一份新的完整 BSP 配置覆盖过去。
4. 显示口仍然是例程的 `lv_port_disp.c`（240×240，RGB565，半屏缓冲）。不要加触摸驱动。
5. 入口是例程 LVGL 线程调用的 `lv_user_gui_init()`，它再调用 `garage_ui_init()`。不要在 `main` 里直接调用。
6. 编译下载后按复位。串口应看到 `[garage_ui] tower deck ready`。先看待机环和时钟，再按任意键进入甲板。

`demo/assets` 里的 `IMG_*` 和 `Font_RexBold_*` 是例程原图，本界面不链接它们，避免占 Flash。界面用的是 `font_garage_16.c` 和 `font_garage_20.c`（文泉驿微米黑，覆盖本界面的汉字、数字和空格）。缺字会回退到同号的 Montserrat。

时钟有 RTC 设备时按 RTC 走，否则从 21:06 开始走，只显示时和分。

## 演示顺序

1. 待机：绿是有车，蓝是托盘，灰是空位，琥珀色方框是对接位。中心数字是空位。
2. 任意键打开甲板。存车右侧是空位数，取车右侧是在库数。
3. 存车 → 右键确认车已停上托盘 → 上下改空位 → 右键开始。看四步文案和进度环，目标格跟着变色。
4. 完成后对接位应预置下一块托盘。再取车，列表里不应出现对接位。
5. 取车过程中按左键，车位应回到按下开始之前。
6. 取完按右键确认驶离。若按左键，再点存车会进 E02，右键仍可确认驶离。

## 逻辑自检

不依赖板子的状态机测试：

```bash
gcc -std=c11 -Wall -Wextra -Werror \
  -I firmware/spark_garage_lvgl/applications/lvgl/demo \
  firmware/spark_garage_lvgl/tests/test_garage_model.c \
  firmware/spark_garage_lvgl/applications/lvgl/demo/garage_model.c \
  -o /tmp/test_garage_model && /tmp/test_garage_model
```

测试覆盖对接位不计入车位、存车调托盘、预置、取车先退托盘、中止恢复、故障恢复和到顶到底。它不代替上板看字号和重叠。
