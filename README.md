## 当前硬件方案

当前评审版本为 **硬件方案 v2 / 采购清单 v3**：保留两层 2×2、每层最多 3 辆；采用侧置共用升降台与上方 X/Y 抓取移盘。新的估算外轮廓约 550×300×670 mm。此版本仍须完成结构建模、单层样件和电气/负载验证，不能直接作为最终加工图。
