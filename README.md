# 模块化塔式立体车库调度系统

第十九届重庆市大学生单片机应用设计竞赛 · 方向三
平台：星火一号 / STM32F407ZGT6 + RT-Thread 标准版

## 当前状态（2026-11-10）

**设计定稿，尚无实物。** 方案、三维模型、引脚分配和调度逻辑仿真已完成；机械件未加工，电路板未投板，固件只有调试界面，电机控制尚未开始。

- **结构**：中央升降转运台，加上每层 8 个辐射排列、无电机的车位。整机只有 3 个运动轴：升降、旋转、转运拨叉。拨叉与托盘的啮合 / 脱开靠升降上下 8 mm 完成。
- **规模**：计划书按两层、14 个车位写；样机先做一层、7 个车位。
- **电气**：3 个 TMC2209 模块 + 2 个 MCP23017 模块，插在 4 块自制转接 PCB 上；霍尔和红外用 5 V。
- **人机界面**：最终用 TJC4827T143 串口屏；开发阶段先用板载 LCD + LVGL 调试。
- **外形与预算**：约 520×520×275 mm。一层样机预算约 ¥1,487，两层约 ¥1,701，均含 15% 机动费。

关键节点：网上报名截止 2026-12-10 20:00；初赛材料提交截止 2027-03-11 20:00。

## CAD 交互演示

用电脑浏览器直接打开 [三维演示](docs/cad/assembly-exploded.html)：

- 点击“存入车辆”，或先选中一个载车托盘再点“取出车辆”。演示过程包括旋转、升降、拨叉啮合与推拉、DOCK 人工确认、空闲预置空托盘、取消存车、暂停和模拟急停。
- 勾选“仅一层样机”，可以切换到一层配置。
- 网址后加 `?view=top` 打开俯视视角，加 `?layers=1` 直接打开一层配置。

页面基于 v3 尺寸，仅用于演示原理，与 v7 模型存在差异；页面不连接实际设备，模型不能作为加工图。Three.js 已放在本地，不依赖网络。
